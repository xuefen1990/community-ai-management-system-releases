# 承包费发放中心使用说明

## 功能入口

登录社区AI管理系统后，从左侧选择“资金发放中心”。首期提供承包费发放，页面分为：

- 发放总览
- 合同发放台账
- 发放记录
- 待处理事项

## 第一步：建立合同

点击“新建合同”，填写合同名称、承包人、合同金额以及完整的开始和结束日期。合同可以关联已有土地档案，也可以不关联。

合同原件、扫描件和相关表格可作为附件保存，之后在合同详情中直接打开。合同到期续签时，应创建新合同；可以复制旧合同的长期发放台账，旧合同和历史发放记录不会被覆盖。

## 第二步：第一次导入长期台账

只有系统还没有该合同台账时，才需要上传 Excel 发放表。

1. 选择表格对应的合同。
2. 选择表格涉及的一个或多个居民组。
3. 选择 Excel 文件并等待识别。
4. 核对姓名匹配、人口或亩数、单价、金额和银行卡号。
5. 对重名或未自动匹配的行，手动指定居民。
6. 银行卡号与居民档案不一致时，明确确认是否采用表格卡号。

系统只在所选组别内按姓名匹配。确认后，银行卡号会补充到居民档案，并建立该合同唯一的长期发放台账。同一居民不能在一次导入中重复出现。

以后每年发放时，不需要重新上传 Excel，直接从长期台账新建发放批次。

## 第三步：新建并核对发放批次

在“合同发放台账”中点击“新建发放批次”。系统会按人口或亩数乘以单价自动计算，并带入长期台账中的银行卡号。

实际金额可以手动修改，但必须填写修改原因。合同金额与居民发放总额不一致时，也必须填写差额用途说明。差额可以是无需向居民发放的合同资金，系统只要求说明，不会强行阻止。

居民档案状态发生变化时，系统只提示，不自动删除台账人员。需要更换领取人时，应在长期台账中填写原因；更换只影响以后新建的批次，历史批次保留原姓名和卡号。

## 第四步：按组导出和登记结果

批次核对完成后，点击“按组导出”。如果一份合同涉及多个组，系统会为每个组分别生成一个 Excel 文件；组内只有部分居民时，也按实际台账人员导出。

线下提交银行处理后，在“登记结果”中逐人标记：

- 已发放
- 发放失败
- 本次未发放
- 待发放

个别失败不会影响其他居民。失败和未发放记录会继续显示在“待处理事项”，不会自动并入下一批发放。

## 承包人到账和居委会垫付

承包人缴费与居民发放相互独立。承包人缴费只记录“未到账”或“已全额到账”，不记录多缴、少缴或部分到账；应填写实际到账日期。

居民催要时，居委会可以先行垫付。垫付记录会显示在“待处理事项”，承包款到账并归还垫付款后，再登记实际归还日期。

## 数据留痕规则

- 合同显示完整起止日期，承包人到账日期和居民发放日期分别保存。
- 一份合同只保留一份长期发放台账。
- 每次发放形成独立批次，历史欠发不与新批次自动合并。
- 历史批次保存当时的姓名、组别、计算依据、金额和银行卡号快照。
- Excel 仅用于首次补充台账，日常发放以系统长期台账为准。
