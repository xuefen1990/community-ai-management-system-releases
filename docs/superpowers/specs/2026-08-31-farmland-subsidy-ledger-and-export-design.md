# 年度地力补贴关联台账与附件导出设计

**日期：** 2026-08-31  
**状态：** 已确认，待实施  
**范围：** 资金发放中心中的地力保护补贴年度台账、核对、预览、打印、导出与历史查询。

## 1. 目标

把现有地力补贴 Excel 的多张关联附件纳入系统管理。工作人员只维护一份完整的年度补贴主表，系统自动生成分户登记清册、村干部清册、分村汇总表、村干部汇总表和兑付清册，避免同一人员在多张表中重复录入而产生人员、面积或金额不一致。

系统应保留每年度的数据和更正历史，使本年度上报后的反馈修改能够被记录，并作为下一年度建立台账时的正确基础。

## 2. 数据范围与关联关系

### 2.1 年度主表

每个年度建立一套独立的“地力补贴年度主表”。一位补贴对象在一个年度中仅有一条主记录，至少包含：

- 年度、村（居）、村民组；
- 补贴对象类别：普通农户或村干部；
- 姓名与居民档案关联；
- 土地确权/补贴依据面积、排除面积、应享受补贴面积；
- 补贴标准、补贴金额及人工调整原因；
- 身份证号、开户行、一卡通号；
- 备注、数据状态和修改记录。

金额默认按“应享受补贴面积 × 补贴标准”计算。工作人员可以修改实际金额，但必须填写调整原因。

### 2.2 居民关联

导入或新建主记录时，系统按以下顺序关联居民档案：

1. 身份证号唯一匹配；
2. 无身份证号时，按“村民组 + 姓名”唯一匹配；
3. 重名、未匹配或资料冲突的记录必须由工作人员手动确认。

### 2.3 附件生成关系

附件不是独立可编辑数据源，全部由年度主表生成：

| 输出表 | 生成范围 | 主要字段 |
| --- | --- | --- |
| 附件 1-1 | 普通农户，按村民组生成 | 户主、面积、排除面积、应补面积、标准、金额、联系电话、签字 |
| 附件 1-4 | 村干部 | 户主、补贴依据面积、排除面积、应补面积、标准、金额、联系电话、签字 |
| 附件 2-1 | 普通农户按组汇总 | 组别、户数、各类面积、补贴金额 |
| 附件 2-4 | 村干部汇总 | 户数、各类面积、补贴金额 |
| 地力补贴兑付清册 | 所有补贴对象 | 身份证、开户行、一卡通号、村、组、面积、标准、金额 |

任意主表数据修改后，所有附件预览与导出结果随之重新计算。附件页可查看来源记录，但不能直接修改。

## 3. 导入、核对与更正

### 3.1 导入

支持导入现有的整套补贴 Excel。系统识别“地力补贴兑付清册”作为完整主数据来源；附件 1-1、附件 1-4、附件 2-1、附件 2-4 用于交叉核对。也支持逐人新增和修改年度主表记录。

### 3.2 核对

导入完成后显示类似 Excel 的主表编辑界面，并单列异常：

- 居民档案未匹配、重名或身份证冲突；
- 身份证号、开户行或一卡通号缺失；
- 同一人员在附件与兑付清册的关键字段不一致；
- 分户、分组汇总、村干部汇总和兑付清册的人数、面积或金额不一致。

未处理异常的台账不得生成正式导出文件。

### 3.3 上报后更正

台账可在已导出或上报后进入“退回更正”状态。每次更正必须记录修改前后值、修改原因、时间和经办人，并标记受影响的附件需要重新生成。

系统保留旧导出版本用于追溯，但下一年度复制基础信息时，只使用本年度最后确认的正确数据。

## 4. 预览、打印、导出和查询

### 4.1 预览与打印

- 年度主表为可编辑表格；附件为只读打印预览；
- 补贴附件统一采用 A4 排版；
- 保留现有样表的标题、单位、合并表头、字段顺序、汇总行和签字栏；
- 可按某一村民组、村干部、全体兑付清册或整套附件预览；
- 打印前检查分页与重复表头，确保多页表格可核对。

单位、街道/社区名称等抬头字段从系统单位基本信息自动带入，并允许在当前年度台账中临时调整。

### 4.2 导出

导出一份完整 Excel，含以下五个工作表且名称与现有样表一致：附件 1-1、附件 1-4、附件 2-1、附件 2-4、地力补贴兑付清册。支持另行导出某个组的分户登记清册。

### 4.3 查询

支持按年度、村民组、姓名、身份证号及金额范围查询。历史年度可重新打开、预览、打印和导出；任何查询结果均显示其更正与导出记录。

## 5. 边界与后续衔接

- 本功能只管理地力保护补贴的年度台账与附件，不改变已确认的工资、公共服务人员、杂工和承包费模板规则；
- 工资、公共服务人员、杂工使用 A5 模板；承包费和地力补贴附件使用 A4 模板；
- 所有资金发放类型共享居民档案与银行卡资料，但各自保留独立的业务字段、计算规则和打印模板；
- 导入的身份证号与银行卡号属于敏感信息，只在有权限的主表与兑付清册中显示和导出。

## 6. 验收标准

1. 导入一套现有补贴 Excel 后，系统可以关联并建立唯一的年度主表；
2. 主表中的每项人员、面积和金额变化都会同步反映到相关附件；
3. 系统可以发现并阻止关键人员、面积、金额不一致的正式导出；
4. 导出 Excel 有完整的五个工作表，字段与版式符合提供的样表；
5. 退回更正有原因和完整变更记录，下一年度复制的是最后确认数据；
6. 可按年度、组别和个人查询、再次打印和再次导出。
