# 管理后台根路径跳转设计

## 背景

当前管理后台通过 `https://xuefeng0901.cn/admin/` 访问。用户希望直接输入域名根路径时也能进入管理后台，同时保留现有 `/admin/` 路径，避免改动前端资源和接口路径。

## 方案

在后端 Express 中增加根路径处理：当请求路径为 `/` 时返回临时重定向到 `/admin/`。

示意：

```js
app.get('/', (_req, res) => res.redirect(302, '/admin/'));
```

路由放在静态后台资源路由之前，并保持现有 `/api/*` 和 `/admin/*` 路由不变。访问 `https://xuefeng0901.cn` 后，浏览器地址栏会显示 `https://xuefeng0901.cn/admin/`，页面进入现有管理后台登录页。

## 选择理由

- 不修改后台页面内部资源路径和 API 路径，风险最低。
- 保留 `/admin/` 作为明确的后台入口，方便后续增加网站首页或其他路由。
- 使用 302 临时跳转，便于以后调整入口而不受浏览器永久缓存影响。

## 验证

1. 本地检查 Express 路由顺序和语法。
2. 将后端入口变更部署到 ECS 并重启后端任务。
3. 访问 `https://xuefeng0901.cn`，确认自动跳转到 `/admin/`。
4. 确认原地址 `https://xuefeng0901.cn/admin/` 仍可直接打开并登录。
