# 永久授权识别与点击安装设计

**日期：** 2026-08-21  
**版本目标：** 0.1.3（Apple 芯片 Mac 测试版）

## 目标

修复已获得永久授权的本机主账号仍被旧“免注册体验”弹窗拦截的问题；将首次安装从拖拽式 DMG 改为双击即可安装的 macOS PKG 安装包。新版本发布到现有 GitHub Releases 仓库，业务源代码不上传。

## 授权识别与启动流程

应用启动时，本地账号服务是授权状态的唯一来源：

1. 已记住的账号自动恢复登录。
2. 当账号的 `entitlement.plan` 为 `permanent` 时，返回“永久授权”，直接进入工作台。
3. 旧版本遗留的“免注册体验 3 天”逻辑不得再显示弹窗、模糊工作台或阻断永久授权账号。
4. 原有账号若缺少新版授权字段，启动时迁移为本机主账号并授予永久授权；已有明确授权记录不被覆盖。
5. 新注册账号仍为 30 天试用；本机主账号仍可在授权管理中为其他账号设置永久或到期授权。

## 安装包与更新

首次安装发布标准 macOS `.pkg`：用户双击后按“继续”与“安装”，应用自动写入 `/Applications/社区AI管理系统.app`。不再发布或要求用户使用拖拽安装的 DMG。

自动更新仍使用 GitHub Release 中的 ZIP 和 `latest-mac.yml`：应用已由 PKG 安装到 Applications 后，启动检查更新；发现新版本时仅提示，用户点击“立即更新”才下载。PKG 仅服务于首次安装，ZIP 仅服务于自动更新。

## 发布文件

`v0.1.3` Release 上传：

- `community-ai-management-system-0.1.3-arm64.pkg`：首次安装。
- `community-ai-management-system-0.1.3-arm64.zip`：自动更新下载。
- `latest-mac.yml`：自动更新清单与 ZIP 校验信息。

Release 说明写明：下载 PKG、双击后按提示安装；不再要求拖拽。

## 错误处理和数据保护

- 永久授权状态读取失败时，不将其误判为“免注册体验到期”；显示简短的“授权信息读取失败”提示，并保留本地业务数据。
- PKG 生成或签名失败时，不上传不完整文件。
- 更新检查或下载失败时，保留当前已安装版本和用户数据。

## 验证

- 单元测试：永久账号启动可进入工作台；遗留单账号被迁移为永久主账号；新账号仍为 30 天试用。
- 界面测试：永久授权状态不会触发旧体验弹窗。
- 构建验证：PKG 安装载荷位置为 `/Applications/社区AI管理系统.app`，签名有效；ZIP、清单版本、文件名和 SHA-512 一致。
- 发布后验证：从 Release 下载 PKG，双击安装后打开应用，永久账号直接显示“永久授权”并进入工作台；手动检查更新能正确读取发布清单。

## 范围边界

本版本仍不包含 Apple Developer ID 的正式签名和公证。测试版可能需要在 macOS 的安全提示中确认打开；获得证书后沿用本流程加入正式签名与公证。
