# 社区AI管理系统 v0.2.5 启动授权识别与登录响应修复设计

## 目标

消除 v0.2.4 旧试用弹窗拦截造成的启动卡顿、无法输入和无法点击问题。对于上次登录且已购买或已授权的账号，应用启动时不显示旧版“免费体验已结束”弹窗；该弹窗即使被旧代码创建，也会在浏览器绘制前从页面中移除。

## 范围

- 发布版本为 v0.2.5。
- 保持手动登录：读取上次账号的授权摘要不得创建登录会话，也不得读取或暴露密码。
- 仅处理旧版试用弹窗；不修改账号密码、授权码校验和工作台业务功能。
- 删除 v0.2.4 的全页面持续监听，不再观察任意样式变化或工作台节点更新。

## 启动授权摘要

主进程提供专用的“启动授权摘要”接口：

- 从本地账号状态中定位上次登录账号（优先记住账号，其次上次登录手机号）。
- 仅返回是否存在历史账号及其授权类型、计划和到期信息；不返回密码，不将账号标记为已登录。
- 本地离线授权码仍按现有签名验证规则计算，因此已购买、永久授权或未过期的期限授权都会被识别为有效授权。
- 没有历史账号、试用账号或已到期账号保持未授权状态，仍只能通过新版登录/激活流程进入系统。

## 启动顺序与旧弹窗移除

1. 本地认证启动代码先于旧版兼容脚本加载，读取启动授权摘要。
2. 若上次账号具有有效购买或授权，安装一个短期、只观察新增节点和文本的启动拦截器。
3. 拦截器检测到“免费体验已结束”或“免注册体验已结束”节点时，移除对应弹窗根节点及其遮罩节点；不使用 `display: none`、模糊滤镜或覆盖层。
4. 此拦截器只在旧脚本初始化窗口内运行，发现并移除弹窗后立即结束；若未发现，则在固定短时限后结束。
5. 启动过程只显示新版登录页，用户仍需手动点击登录进入工作台。

## 交互与性能

- 不再使用对整个文档 `class`、`style` 和子树变化的永久监听。
- 登录页不再被后台逻辑反复改写，输入框、密码显示按钮和登录按钮保持正常响应。
- 登录成功后沿用原有兼容工作台加载流程；进入前执行一次定向旧节点移除，不保留任何后台观察器。
- 试用到期和未授权用户使用新版、可操作的登录/离线激活提示，绝不展示旧版体验结束弹窗。

## 失败处理

- 无法读取启动授权摘要时按未授权处理：显示登录页，不自动进入工作台，也不阻断用户输入。
- 旧弹窗 DOM 结构变化时，按标题匹配最近的对话框或遮罩根节点；删除失败不会影响登录界面。
- 授权到期时仍须手动登录后进入新版激活流程，不能仅凭历史摘要进入工作台。

## 验收与验证

- 已购买或已授权历史账号启动时不显示旧试用弹窗，登录页可立即输入和点击。
- 不会恢复登录会话；用户必须手动登录。
- 旧弹窗节点被直接移除，页面没有模糊层或残留点击拦截层。
- 登录后工作台的主要导航和按钮可点击。
- 自动化覆盖启动授权摘要、无自动登录、短期拦截器、旧节点移除及无全页持续监听。
- 运行完整测试套件，构建并挂载检查 v0.2.5 arm64 拖拽安装 DMG。
