# 资金发放中心：在线表格、模板与 Excel 导入设计

## 目标

将资金发放中心建设为统一的发放制表工作台。工作人员可导入既有的、含人员和金额的 Excel 发放明细，或基于模板新建批次；随后像使用 Excel 一样编辑、预览、打印，并在发放完成时将已经人工确认的银行卡等资料同步至居民档案。

本功能不承担日常收支入账职责，也不会在发放完成后自动生成财务收支记录。

## 使用边界

- 资金发放中心负责人员名单、发放金额、银行卡、打印表和发放状态。
- 财务收支台账独立管理；两者不自动入账、不自动生成凭证。
- 模板采用配置式表格，不提供 Excel 式任意拖拽排版或自由合并单元格。
- 所有模板均可自定义；内置工资、公共服务、杂工、承包费等模板只是起点。

## 模板管理

每个模板包含以下配置：

- 标题、编制单位、日期显示方式和单位。
- 表头字段、字段顺序和列宽。
- 字段来源：居民档案字段、批次填写字段、手工字段或计算字段。
- 计算规则，例如单价乘数量、月标准乘月份、面积乘标准。
- 打印设置：A4 或 A5、横向或纵向、每页人数、合计栏及审批／制表签名栏。

模板可由两种方式创建：从空白新建，或复制任一现有模板后调整。模板修改只影响之后新建的批次；每个批次创建时保存模板快照，历史批次的格式、字段和计算逻辑不会随模板更新而变化。

## 批次编辑与居民联动

新建批次后选择模板，再通过选择居民、手工增加人员或导入 Excel 填充发放表。

- 选择居民时，自动带入姓名、组别、身份证、默认发放银行卡及模板要求的其他居民档案字段。
- 多个同名居民必须显示组别、身份证或银行卡尾号，操作员必须人工确认具体居民。
- 在线发放表支持增删人员、编辑字段、自动计算金额和手工调整金额；手工调整金额必须填写调整原因。
- 居民档案支持多张银行卡，并明确其中一张为默认发放卡。
- 表内修改银行卡时，操作员必须选择“仅本次发放使用”或“同时更新居民档案并设为默认发放卡”。前者不更改档案，后者新增或更新该居民的银行卡资料。

## Excel 导入与同步

导入对象是含人员、金额、银行卡及其他业务资料的现成发放明细，而不是单纯空白格式文件。

导入流程如下：

1. 操作员选择 Excel 文件，系统识别表名、标题、表头、人员、金额、银行卡及可识别字段。
2. 系统将内容生成一笔“核对中”的在线发放批次，保留原始导入数据供追溯。
3. 系统按身份证优先、姓名加组别其次的规则尝试关联居民。
4. 匹配成功且银行卡一致的记录进入可确认状态；卡号不同、重名或未找到居民的记录进入待处理清单。
5. 操作员在表内补改、增删、处理待确认项并完成打印预览。
6. 点击“发放完成”时显示同步清单。仅已经确认关联的资料会写入居民档案；冲突或无法确认的记录不会自动覆盖或写入。

同步结果需记录：是否关联居民、同步字段、原值、新值、操作员选择和时间。

## 预览、打印与状态

发放表改变后，预览即时反映最新内容。预览页面提供：

- A4／A5、横竖版、每页人数和打印份数。
- 是否显示完整银行卡与审批／制表签名栏。
- 当前页预览、页面缩略图和分页切换。
- 导出 Excel 及确认打印。

默认批次状态为：`核对中` → `准备打印` → `已打印` → `发放完成`。

“发放完成”后，批次锁定，防止人员、金额和账号被误改。若发现问题，使用“更正批次”记录调整原因，原批次、原导入数据、原打印快照和原同步记录均保留不变。

## 数据结构与职责

- **模板**：字段、字段来源、计算规则及打印配置。
- **发放批次**：模板快照、业务信息、状态、总额、打印记录和导入来源。
- **发放明细**：当次人员、金额、银行卡、手工修改和关联状态。
- **居民关联结果**：匹配依据、候选项、人工确认结果和冲突状态。
- **银行卡记录**：归属居民、卡号、是否默认、来源及变更记录。
- **同步记录**：批次完成时写入居民档案的实际字段变更。

## 异常处理

- Excel 表头无法识别时，进入字段映射确认，不能直接完成导入。
- 导入中姓名重名、身份证冲突或银行卡不同，进入待处理清单，不能静默覆盖。
- 居民档案不存在匹配人员时，可只保留本次发放数据；不自动创建居民档案。
- 打印前提示未处理的关联冲突；允许预览，但“发放完成”前必须明确跳过或处理。
- 保存失败或同步失败时，保留发放表和待同步清单，允许安全重试，不重复写入银行卡记录。

## 验证范围

- 导入识别和字段映射。
- 身份证、姓名加组别及同名居民的关联规则。
- 银行卡仅本次使用／同步居民档案两种选择及多卡默认规则。
- 模板快照和历史批次隔离。
- 在线编辑、自动计算、手工调整原因和金额汇总。
- A4／A5 自动分页、预览与打印内容一致。
- 批次锁定、更正批次和同步失败重试。
