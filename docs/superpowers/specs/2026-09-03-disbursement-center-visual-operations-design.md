# 资金发放中心可视化操作与居民资料统一同步设计

**日期：** 2026-09-03  
**状态：** 已确认，待开发  
**范围：** 资金发放中心的批次清理与复制、模板调整、打印预览布局、所有发放表的居民资料同步，以及可视化核对与查询。

## 1. 目标

将资金发放中心提升为清晰、可视化且安全的报账工作台。操作人员能够直观看到发放进度、资料缺失或冲突、模板样式和打印结果；测试数据可以安全清理，正式历史记录不会因后来修改模板或居民资料而改变。

## 2. 发放批次

### 2.1 测试批次与清理

- 新建或复制批次时可标记为“测试批次”；列表支持单独筛选。
- 删除以整笔发放批次为单位，包含该批次全部人员明细、金额、打印版式快照与关联记录；不提供已发放单个人员明细的单独删除。
- 删除操作为“移入资金发放回收站”，可恢复；管理员可在回收站手动彻底清除，不自动过期删除。
- 无论草稿、已打印或已发放的测试批次，都可移入回收站；界面必须清楚显示批次名称、期间、人数和金额并进行二次确认。

### 2.2 复制批次

- 复制生成新的“草稿”批次，原批次不变。
- 复制人员、金额、业务字段、计算规则、纸张、方向、每页人数、边距、列顺序、列宽及显示字段。
- 复制时重新读取居民档案的最新资料。银行卡号等资料发生变化时，提示对应人员；重名仍须按组别、身份证或卡号尾号人工确认。

### 2.3 可视化状态

每个批次显示明确状态：`草稿`、`准备打印`、`已打印`、`已发放`。

同时显示居民资料状态：

- `已同步`：该批次所有可同步资料均已完成核对；
- `待同步 N 人`：可点击进入同步预览；
- `待人工确认`：含重名、资料冲突或缺少关键资料的人员。

已打印、已发放批次保留当时快照。如需改动发放内容，使用“复制批次”生成新草稿，避免正式历史记录和实际发放情况不一致。

## 3. 模板与打印预览

### 3.1 默认模板可编辑

- 内置默认模板不再锁定，管理员可以直接调整标题、字段、列顺序、列宽、签字栏、纸张、方向、每页人数和边距。
- 默认模板修改仅影响之后新建的批次；已有批次继续使用生成时的模板快照。
- 提供“恢复系统原始模板”，不提供模板历史版本管理。
- 预览调整后可选择“保存到当前模板”或“另存为新模板”。

### 3.2 预览版式编辑

- 打印预览增加明确的“编辑布局”模式，防止误操作。
- 允许拖动列头调整列顺序、拖动列边界调整宽度、显示或隐藏字段。
- 不支持自由移动单元格或合并单元格，保证每种表格的打印稳定性。
- 纸张、方向、每页人数和边距继续在预览侧栏调整，所见即所得。

## 4. 所有发放表统一同步居民资料

### 4.1 适用范围

统一适用于地力补贴、承包费、固定工资、村组干部工资、党小组长补贴、监督委员补贴、公共服务人员报酬、杂工，以及后续新增的所有资金发放模板。

### 4.2 同步流程

1. Excel 导入或人工录入后，系统按身份证号优先、姓名加组别辅助匹配居民；
2. 显示“资料同步预览”，不在仅上传时直接写入居民档案；
3. 居民资料为空时，可补充身份证号、手机号、银行卡号、开户行、组别等已识别信息；
4. 同一资料不同值时，操作员选择“采用新资料”或“保留居民档案原资料”；
5. 重名或无法确定的人员必须人工选择；
6. 点击确认后，才写入或更新居民档案，并记录来源批次。

居民档案需显示“联系与银行卡”及“资金记录”信息，便于查看银行卡号和该居民历次补贴、工资、承包费等发放情况，并可打开对应发放表。

## 5. 可视化核对与快速查询

### 5.1 发放前核对卡

在新建和预览前显示可点击的核对卡，集中展示：

- 重名待确认；
- 无银行卡号；
- 银行卡号更新；
- 金额手动调整及原因；
- 同一人员同一期间重复出现。

点击任一提示应直接定位到对应人员行。

### 5.2 模板卡片与步骤条

- 模板以卡片展示名称、适用业务、纸张、方向和每页人数；
- 新建流程显示：选择模板 → 添加人员 → 核对数据 → 打印／发放；
- 主表保持行列式编辑，使用居民查询和自动填充银行卡的方式输入人员资料。

### 5.3 快速查询

资金发放中心支持按姓名、身份证号或尾号、银行卡尾号、组别、日期、模板、资金类别、批次状态和测试标记进行查询定位。

## 6. 验收标准

1. 测试批次能整笔移入回收站、恢复或由管理员彻底清除；
2. 任意批次能复制为草稿并继承人员与版式，居民资料按最新档案重新核对；
3. 默认模板可直接修改，历史批次打印结果不受影响；
4. 预览可调整列顺序、列宽和显示字段，并能覆盖当前模板或另存新模板；
5. 所有资金发放表均能通过“同步预览 → 确认”把可确认资料写入居民档案；
6. 存在重名、卡号或手机冲突时不自动覆盖，必须人工确认；
7. 可通过批次资料状态、核对卡和查询功能快速发现、定位并处理问题；
8. 居民档案可查看银行卡和对应的资金发放记录。
