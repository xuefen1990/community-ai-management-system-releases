# 全系统按钮可用性巡检与修复设计

日期：2026-08-24

## 目标

对桌面端所有可见页面的按钮、链接、菜单入口和关键操作进行可用性巡检。修复能够确定的无响应、空实现和错误绑定问题，并交付明确的验证清单。

已知首要问题为“村民一户一档 → 导入人员 → 批量导入人员”：桌面端文件选择接口当前固定返回空结果，导致点击后没有任何反馈。

## 巡检范围

- 侧栏菜单、工作台快捷操作和底部账户操作。
- 村民一户一档、党员管理、民情记录、村里值班、财务收支、工作管理、土地承包确权、文书拟写、证明开具、电子档案柜、系统设置。
- 需要桌面端权限的入口：选择文件、读取 Excel、导入/导出、打开文件夹、打印和更新下载。

## 检查方法

每个入口按以下三层检查：

1. **界面绑定**：存在有效的事件处理函数或事件监听器。
2. **桌面端通道**：通过预加载桥暴露的调用在主进程中存在对应处理器。
3. **真实结果**：处理器不返回固定空值，能触发文件选择、数据读写、导出或状态更新。

静态检查用于建立覆盖清单；自动化测试覆盖关键主进程接口和已修复的 UI 绑定；本机人工验证仅用于必须依赖用户文件、打印设备或外部服务的步骤。

## 修复原则

- 优先修复无响应、调用空接口、阻塞业务和可能误导用户的入口。
- 不在巡检期间执行真实的“删除全部”“清空数据”等高风险操作；仅验证二次确认与调用链。
- 所有修复的入口在处理中显示反馈，失败时显示用户可理解的原因。
- Excel 导入先恢复选择 `.xlsx/.xls` 文件，再读取表头、预览数据、校验后写入；取消选择不报错也不写入数据。

## 验收与交付

- 生成巡检结果清单，分类为“已验证可用”“已修复”“需本机人工确认”。
- 自动测试覆盖 Excel 文件选择与人员导入链路，以及按钮绑定完整性。
- 所有改动通过测试后构建新版本；更新 ZIP 发布至后端，DMG、ZIP 和说明同步发布至 GitHub。
