# 居民编辑与 AI 交互改版

用户已通过对话确认并授权实现。保留编辑登记窗口原有 UI、左侧导航及平滑滚动。加入收款账户、扩展资料、费用发放记录、操作记录、来源与更正记录。账户入口直接定位收款账户，编辑入口定位基础信息。栏目间保留输入，确认保存统一提交；未保存关闭需提醒。

AI 取消左侧独立对话菜单，改为右下角可拖动入口和小对话窗。仅本次运行保留拖动位置，每次启动恢复右下角。页面切换保留对话。AI 操作记录保留独立入口，用中文动作、操作人、时间、前后对照、状态和可撤销原因替代代码展示，沿用主进程现有撤销与冲突保护。

实施顺序：完整备份 → 居民统一编辑 → AI 悬浮与记录 → 数据保存/冲突/撤销/拖动及原页面回归 → 下一版本本机更新。不得上传 GitHub。
