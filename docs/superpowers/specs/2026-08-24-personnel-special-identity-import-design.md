# 专项人员信息导入合并设计

## 目标

将党员、退役军人等专项人员表导入到统一的居民档案库。系统以身份证号为唯一合并凭证：同一身份证号只保留一份居民档案，并为其补齐信息和专项身份标签。

## 用户流程

1. 用户从“导入人员”选择 Excel 文件。
2. 系统读取文件名、工作表名和表头，自动推断专项身份；例如包含“党员”的表推断为“党员”，包含“军人、退役军人、退伍”的表推断为“退役军人”。
3. 导入映射窗口展示推断结果和标签选择器。用户可以确认或手动改为支持的其他专项身份。
4. 用户确认导入后，系统逐行用身份证号查找居民档案：
   - 找到唯一匹配档案：保留档案已有内容，填入本次导入的非空字段，并追加专项身份；已有相同身份不重复添加。
   - 未找到匹配档案：新建居民档案，写入本次非空字段和所选专项身份。
   - 身份证号为空或格式不合法：不使用姓名、手机号等次级条件自动合并；该行跳过并在结果中说明原因，避免同名误合并。
5. 导入完成后刷新居民列表、身份筛选和顶部统计，并提示新增、合并、跳过数量及标签追加情况。

## 数据与兼容性

- 居民记录新增一个可扩展的 `specialIdentities` 标签数组，用于保存“党员”“退役军人”等专项身份。
- 对现有布尔字段（如 `is_party_member`、`is_veteran`）保持兼容：导入时同步写入对应字段；查询和统计同时识别旧字段与新标签，历史数据无需迁移即可继续显示。
- 标准标签先覆盖现有筛选项：党员、退役军人、低保户、特困人员、残疾人、学生、务工人员、脱贫户、雨露计划、监测户。标签选择器同时允许选择“其他”并输入自定义标签。
- 身份证号比较时去除前后空白、统一大写；只以清洗后的身份证号匹配。遇到本地数据中同一身份证号存在多条记录时，跳过该行并记录“本地身份证号重复”，不擅自选择其中一条。

## 自动识别规则

- 识别来源按优先级：文件名与工作表名、表头、用户手动选择。
- 命中多个标签或未命中标签时，默认不自动指定标签，要求用户在导入窗口选择后才可继续。
- 自动识别仅设定本次导入标签，不改变表头字段映射；身份证号和姓名仍由用户确认映射。

## 写入规则

- 只写入用户在映射界面明确选择的列；未选择列不触碰原档案。
- 对已有居民，导入字段为非空时更新该字段；空值不覆盖原值。
- 标签采取并集，永不因一次导入删除已有标签。
- 将识别/手选的标签、文件名、总数、新增数、合并数、跳过原因统计写入导入记录，便于追溯。

## 异常与提示

- 没有身份证号映射时，确认按钮不可用，并说明专项合并必须使用身份证号。
- 空姓名、空身份证号、无效身份证号、本地身份证号重复均列为可见的跳过原因。
- 保存失败时不关闭窗口、不刷新界面，并保留映射和选择供用户重试。

## 验收与测试

- 居民表已有“张三 / 其身份证号”；导入党员表中同一身份证号后，系统仅保留一条张三档案，追加“党员”标签并保留原有资料。
- 再导入同一身份证号的退役军人表，档案同时拥有“党员”和“退役军人”标签，且不产生重复记录或重复标签。
- 系统正确自动识别党员、退役军人关键词，用户可以在窗口改为其他标签。
- 空或无效身份证号、重复身份证号、导入字段空值等情况不会误合并或清空既有数据。
- 现有党员、退役军人筛选与统计能显示旧数据和新导入标签数据。
