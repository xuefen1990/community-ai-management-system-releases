# AI 助理居中放大窗口设计

## 目标

保留现有右下角小窗；点击“放大”后改为视口中央的对称对话窗。解决靠右停放、内容挤在左侧、右侧大面积留白、按钮和输入区过小的问题。

## 界面

- 放大窗口宽度最多 920px、高度最多 780px，随应用窗口收窄，四周保留至少 12px。背景加轻度遮罩，以突出当前对话。
- 顶部一行展示“AI 助理”、服务状态、操作记录、记忆、新建对话、缩小和关闭；窄屏时允许次要操作横向滚动。
- 中间仅消息区滚动。回复、任务卡片和文件卡片统一收在约 720px 的居中阅读列；用户消息靠这列右侧。长文本自动换行。
- 底部保持常用提问、附件入口、输入框和发送按钮；控件与阅读列对齐。文件、图片、扫描入口沿用现有功能，只调整放大态的排版。

## 行为与边界

- 放大与缩小不重新挂载聊天组件，不清空对话、附件或输入内容。
- 点击“缩小”或按 Escape 返回小窗；关闭后再次打开仍为小窗。
- 窗口大小变化时重新居中，窄屏时自适应。
- 本次仅调整渲染进程的窗口状态与样式，不修改 AI 调用、业务操作、后端或数据存储。

## 验证

检查放大、缩小、关闭后重开、窗口缩放、聊天滚动、输入区固定、原有操作入口可用；运行相关测试与开发模式检查。
