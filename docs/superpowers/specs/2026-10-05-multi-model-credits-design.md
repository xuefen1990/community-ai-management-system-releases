# 多模型与积分设计

依据本次用户已确认方案实施。后台独立页面批量配置模型卡片；按文字、图片、思考及输入容量选择并在同能力模型间切换。API Key 留在服务器并加密。

真正按积分收费：2,000 Token 基准，普通权重 1、图片 1.5、深度 2，最低 1/2/3 分。一次操作汇总，重试失败不计费，超过 3 分需要确认上限。采用整数最小单位保留余额尾数，后台保留实际 Token。

开发版独立后端启用积分；正式后端部署兼容代码但关闭积分及真实余额迁移。旧接口保留。任务预留和结算幂等、按主账号共享余额。

使用根目录 npm run dev 预览；仅同步本次后端代码至 ECS 并验证。暂不打包、登记更新或上传 GitHub。
