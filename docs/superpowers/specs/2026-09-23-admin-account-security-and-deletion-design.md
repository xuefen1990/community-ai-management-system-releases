# 管理后台账户安全与账号删除设计

## 目标

- 管理员可在后台自行修改密码。
- 密码修改、管理员重置密码、停用和删除账号后，旧令牌立即失效。
- 平台管理员可停用或删除非平台管理员账号；删除后同一手机号可重新注册。

## 会话失效

用户记录增加 `session_version`。签发 JWT 时携带该值，鉴权时比对数据库中的当前值。密码变更、重置、停用、删除时递增该值，因此旧 JWT 无法继续使用。

## 删除语义

使用软删除，不物理清除审计和业务关联：

- 标记账号为 `deleted`、停用并清空认证资料。
- 将原手机号改为不可登录的内部占位值，释放原手机号供后续注册。
- 平台管理员账号不可删除。
- 删除单位管理员时，所属单位改为停用，成员账号同步停用；历史数据仍保留。

## 管理后台

- 增加“账户安全”导航页，可填写旧密码、新密码和确认密码。
- 账号列表增加删除按钮及二次确认，并在删除后刷新列表。

## 验证

覆盖密码变更后旧令牌失效、管理员重置后旧令牌失效、删除后手机号可重新申请、删除单位管理员后单位成员不可再访问。
