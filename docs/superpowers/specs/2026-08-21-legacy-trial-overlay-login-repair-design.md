# 社区AI管理系统 v0.2.4 登录入口与旧试用遮罩修复设计

## 目标

修复 v0.2.3 启动后仍出现旧版“免费体验已结束”弹窗的问题。应用启动时必须只显示新版登录页；旧试用弹窗及其背景遮罩不得阻挡界面。用户手动登录成功后，工作台必须可以正常点击。

## 范围

- 将本补丁发布为 v0.2.4。
- 保留 v0.2.3 的本地账号、钥匙串预填密码和手动登录设计。
- 不改动工作台业务功能、账号校验规则或授权期限。
- 不删除旧版页面代码，只阻止其旧试用弹窗成为启动入口或点击拦截层。

## 设计

### 1. 唯一启动入口

新版登录控制器拥有启动界面的控制权。启动时显式关闭所有旧试用弹窗、背景模糊和点击拦截层，再展示 `panel-login`。启动流程不再调用旧版页面切换函数，避免其将认证面板切换至注册页或旧工作台状态。

### 2. 旧试用逻辑隔离

新增一个专用的旧版试用界面清理函数：

- 查找标题为“免费体验已结束”或“免注册体验已结束”的旧弹窗；
- 隐藏弹窗，禁用其鼠标事件并恢复页面/工作台的模糊效果；
- 清理动作在初始化、显示登录页和成功进入工作台前各执行一次；
- 无论本地账号是永久授权、试用中或授权到期，都执行此清理。授权是否可进入工作台仍由新版认证流程决定。

因此，旧版弹窗不再参与任何授权判断；授权到期时只显示新版的、可操作的激活提示。

### 3. 登录与工作台

启动后读取已保存的预填信息，但不自动登录。用户点击登录并通过现有验证后：

1. 新版认证逻辑判定授权是否可用；
2. 可用时进入工作台，并在切换前再次清理旧遮罩；
3. 不可用时保持在新版认证流程中显示激活提示，且提示可点击；
4. 不允许旧弹窗重新覆盖工作台或登录页。

## 异常处理

- 找不到旧弹窗时，清理函数不做任何操作，不影响正常启动。
- 旧版 DOM 结构变化时，按标题和可访问的对话框/遮罩容器逐层安全处理；不会因清理失败阻断登录。
- 若授权无效，不进入工作台；这是新版授权提示，而非旧版体验结束弹窗。

## 验收与验证

- 启动时不出现“免费体验已结束”弹窗，直接显示登录页。
- 页面没有背景模糊或透明层，登录页控件可点击。
- 手动登录后工作台的菜单、按钮、卡片均可点击。
- 授权不足时显示新版可操作提示，旧版弹窗不出现。
- 为初始化、旧遮罩清理和工作台切换增加自动化覆盖，并运行完整测试套件。
- 构建并挂载检查 v0.2.4 的拖拽安装 DMG，确认应用可启动。
