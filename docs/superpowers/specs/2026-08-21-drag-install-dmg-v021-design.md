# 社区AI管理系统 v0.2.1 拖拽安装包设计

## 目标

将 macOS 发布方式从 PKG 安装包改为标准 DMG 拖拽安装包，让用户打开磁盘映像后将应用拖入“应用程序”文件夹完成安装。

## 已确认范围

- 发布新版本 `v0.2.1`，不改写已公开的 `v0.2.0` 发布内容。
- 发布产物不再包含 PKG。
- 同时保留 ZIP 备用下载，以及用于应用内更新的 `latest-mac.yml`。

## 安装体验

用户下载并双击 `社区AI管理系统-0.2.1-arm64.dmg` 后，会看到：

- `社区AI管理系统.app`
- 指向 `/Applications` 的“Applications”快捷入口

用户将应用图标拖到“Applications”即可安装。DMG 卷标使用“社区AI管理系统”。

## 构建方式

现有 arm64 构建继续负责生成并签名运行时应用。原有的 PKG 构建步骤替换为：

1. 创建干净的 DMG 临时目录。
2. 复制已签名的应用到该目录。
3. 创建 `/Applications` 符号链接。
4. 使用压缩 DMG 格式生成发布文件。
5. 清理临时目录。

自动更新 ZIP 的稳定英文文件名与 `latest-mac.yml` 保持一致，避免下载更新时找不到资产。

## 验证与发布

- 运行现有测试套件。
- 校验应用代码签名。
- 挂载 DMG，确认其中仅包含应用和 Applications 快捷入口，然后卸载。
- 校验 ZIP 与 `latest-mac.yml` 中的文件名、大小和摘要。
- 以 GitHub Release `v0.2.1` 上传 DMG、ZIP 与更新描述文件。

## 不做的事

- 不替换或删除 v0.2.0 的公开文件。
- 不改动登录、授权及界面功能。
