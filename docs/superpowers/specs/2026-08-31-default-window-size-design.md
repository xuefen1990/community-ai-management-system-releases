# 默认窗口尺寸调整设计

## 目标

将“社区AI管理系统”桌面端首次打开时的默认窗口从 1292 × 768 调整为 1600 × 900，使常见 1920 × 1080 屏幕上的工作区更舒展。

## 方案

- 仅调整主窗口的初始 `width` 与 `height`。
- 保持现有最小窗口尺寸 1080 × 680，不改变用户手动调整窗口大小的行为。
- Electron 仍根据 macOS 可用屏幕区域处理窗口位置；较小屏幕不会被强制放大到不可用尺寸。

## 范围与验证

- 修改 `app/src/main/window-config.js` 中的主窗口默认尺寸。
- 补充窗口配置单元测试，确认默认尺寸为 1600 × 900，最小尺寸保持不变。
- 作为桌面 App 界面更新发布下一语义化版本，供已安装用户在 App 内完成更新。
