# 地图与村界、数据统计迁入设计（已确认）

以本机村务通包内 v2.9.7 为参照，迁入地图定位及完整六分区统计，接入本系统现有本机/LAN 数据与权限。只迁代码和资源，不复制村庄数据或服务密钥。用户确认不新增村界绘制。

地图中心与缩放复用 `/api/v3/system-settings`，保存只修改两个地图字段；已有村界、村名不变。Leaflet 本地加载。天地图密钥使用本机 safeStorage；不可用时只保留在当前进程。地名搜索与瓦片请求由主进程访问固定 HTTPS 服务，页面只接收位置和图片，不接收密钥。

数据统计迁入人口、党务、民情、值班、财务、土地六个分区，保留年度、刷新、图表与只读下钻。沿用本系统财务分类、整数分金额和 API 授权。拒绝读取和加载失败分别提示，不伪装成有效零值。大屏在本应用内打开，年度、村名、地图与权限保持一致，不在外部 URL 携带居民资料。

按来源哈希和模块清单生成独立代码、作用域 CSS 与出处记录；不直接手改锁定 vendor。现有生成运行时仅增加经审核的依赖导出，保留其他聊天改动。

使用合成数据验证分页、金额、权限、村界保留、地图保存、瓦片、分区切换和大小窗口。真实密钥联网验收另记。本次无版本变更、Git 提交、打包、发布或 ECS 部署。
