# 正式版统一后端域名设计

## 目标

让正式安装版的账号注册、登录、共享工作区、在线模型调用和更新检查统一使用 `https://xuefeng0901.cn`。

## 方案

- 将 Electron 正式版的默认后端地址改为 `https://xuefeng0901.cn`。
- 开发模式继续使用 `COMMUNITY_DEV_BACKEND_URL` 指向的本机独立后端。
- 对正式版中历史保存的 `http://127.0.0.1:3000`、`http://localhost:3000`、旧 ECS 公网/内网地址进行一次性迁移；其他用户手动配置的地址保留。
- 更新账号服务器设置界面的示例和提示，使其反映公网 HTTPS 部署方式。
- 更新发布同步脚本和后端说明中的默认生产地址。

## 验证

1. 运行远程认证、后端管理相关的现有测试。
2. 检查正式版入口代码默认地址和迁移逻辑。
3. 保持开发模式测试继续使用 `127.0.0.1:3301`。
