# 村居单位账号、权限与实时同步设计

## 目标

将现有以单个本机账号和本机数据为中心的登录方式，重构为按村居单位隔离的多账号协作系统。每个单位只有一名单位管理员；管理员审核成员、分配数据和功能权限。成员可在不同电脑登录并实时协作同一单位的数据。

平台负责审核单位管理员申请并维护其有效期。成员账号的可用期不单独维护：只要所属单位管理员到期、被停用或单位关闭，全部成员同步失效；管理员续期后，成员原有账号和权限自动恢复。

## 角色与组织

### 平台超级管理员

- 审核单位管理员申请，并通过、驳回或停用申请。
- 为单位管理员设置、续期或终止有效期。
- 查看全平台单位、账号和审计记录。
- 不参与各单位的日常数据录入和成员权限分配。

### 单位与单位管理员

- 一个村居或社区对应一个独立单位数据空间，包含稳定的内部编号；单位名称不是隔离依据。
- 每个单位只能有一名单位管理员。平台审核通过其申请后，才可启用该单位。
- 单位管理员只能管理本单位成员、权限、邀请码和数据，不能查看其他单位或修改自身有效期。

### 普通成员

- 成员通过单位邀请码或二维码提交加入申请，默认状态为待单位管理员审核。
- 单位管理员批准申请并分配权限后，成员才可进入工作台。
- 一个手机号只能注册一个账号并归属一个单位，防止跨单位身份和数据边界混淆。

## 登录与申请页面

登录页提供三个独立入口：

1. **账号登录**：输入账号和密码。后端根据账号自动识别所属单位，不要求或允许用户在登录时手选单位。
2. **申请成为单位管理员**：填写单位名称、地区、申请人姓名、手机号和密码；提交后显示待平台审核状态。
3. **申请加入单位**：扫描单位二维码或填写邀请码，再填写本人资料和密码；提交后等待单位管理员审核。

邀请码和二维码只包含受控的邀请码，不包含成员或业务数据。单位管理员可以设置邀请码有效期和可使用人数，可随时作废并生成新的邀请码。

## 权限与数据范围

权限采用“预设岗位加可微调权限”的方式。预设岗位可包括数据录入员、民生走访员、党建专员、台账管理员和只读查看员；管理员可按实际分工调整。

每个业务模块独立配置权限，例如人员档案、走访记录、党务、土地、证明、公文、工作管理、统计导出和系统设置。权限动作至少区分：查看、录入、修改、删除、导出、审核或发布。

数据范围分为“本人创建的数据”和“本单位全部数据”。例如走访员可管理自己填报的记录，台账管理员可管理本单位的全部人员档案。成员管理、权限分配、批量导出和删除等高风险操作默认仅单位管理员拥有；若有明确业务需要，后续再单独授予。

## 统一数据与实时同步

现有每台电脑各自保存 JSON 数据的方式不再作为主数据来源。账号、单位、权限和全部业务数据由服务器上的共享数据库统一保存。

- 每条业务数据带有单位标识、创建人、最后修改人、创建时间、更新时间和版本号。
- 后端在所有查询和写入前校验当前账号所属单位及其权限；前端隐藏不能作为数据隔离手段。
- 桌面端登录后仅加载本单位且当前账号有权访问的数据。
- 后端在数据变更成功后向本单位、有相应查看权限的在线成员发送实时更新通知，使其他电脑自动刷新相关内容。
- 同一记录发生并发编辑时，以版本号检测冲突；后提交者收到已被他人更新的提示，刷新后再决定如何提交，避免覆盖。
- 网络中断时明确显示离线状态；恢复后重新拉取服务器最新数据。敏感数据编辑不在离线状态下本地暂存，以减少冲突和越权风险。
- 历史本机数据通过由单位管理员确认的导出、导入迁移流程进入单位空间，不进行静默合并。

共享数据应使用适合并发访问的正式服务器数据库；现有后端 JSON 文件数据库不承担多电脑实时协作的数据层职责。

## 有效期、状态与审核

单位管理员申请状态包括：待平台审核、已通过、被驳回、已停用和已到期。

成员申请状态包括：待单位管理员审核、已启用、被拒绝和已停用。成员能够登录和访问数据的前提是：成员已启用、所属单位正常、单位管理员仍在有效期内。

平台为单位管理员设置有效期。有效期届满时，后端立即拒绝该单位所有成员的登录和受限数据访问；管理员续期后，成员自动恢复，无需逐人重新开通。每次登录、令牌续期及受保护的数据请求均重新校验这一链路。

## 审计与提示

后端记录申请审核、有效期调整、成员启停、权限分配、邀请码变更、数据修改、删除及导出等关键操作，至少保存操作者、目标、时间、单位和变更摘要。

登录和访问失败须给出具体可执行的原因，例如“申请尚未审核”“单位管理员有效期已到，请联系平台管理员续期”或“当前账号无导出权限”，不使用模糊的“账号错误”。

## 验收标准

- 平台可审核单位管理员申请，且同一单位不能产生两个有效单位管理员。
- 成员只能通过有效邀请码或二维码申请加入，并必须经单位管理员审核及授权后使用。
- 单位管理员到期或被停用后，本单位成员不能登录、读取或修改数据；续期后自动恢复原权限。
- 不同单位的账号不能读取、搜索、导出或实时接收对方数据。
- 同一单位成员在不同电脑上修改获权数据后，其他有权成员可收到并看到更新；并发修改不会静默覆盖。
- 所有关键账号、权限和数据操作均可在审计记录中追溯。

## 非本阶段范围

- 一个账号同时归属多个单位。
- 一个单位配置多个同等权限的单位管理员。
- 离线状态下的可编辑协作与自动冲突合并。
- 自动、无确认地迁移既有本机数据。
