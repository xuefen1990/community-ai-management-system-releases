# 资金发放预览即时设置设计

## 目标

让操作员在打印预览中调整当前批次的纸张、方向和页面边距，并可直接修改或删除未完成批次中的发放明细。姓名与居民档案关联后，应自动带入已有银行卡号和手机号等可映射资料。

## 范围

- 新建、编辑发放表不再显示纸张和方向；模板提供默认值。
- 打印预览左侧提供当前批次的 A4/A5、纵向/横向，以及窄、标准、宽和上/下/左/右自定义边距。
- 设置即时重排预览、分页与缩略图，并保存到当前批次；导出和打印使用同一设置。
- 草稿、待打印批次在预览表格中提供修改、删除。已打印或已完成批次保持锁定。
- 新建表中的“添加人员”采用紧凑按钮。姓名选择或确认居民后，带入居民卡号与可配置居民字段；重名仍要求人工选择。

## 数据与安全

批次 `printSettings` 保存 `paper`、`orientation`、`margins` 和每页人数。模板不因批次调整而变更。删除明细必须二次确认，避免误删；任何保存后的预览改动都复用既有保存失败提示。

## 验收

1. 左侧切换纸张、方向、边距后，预览尺寸、分页、缩略图和打印样式同步变化。
2. 修改、删除一条草稿或待打印明细后，合计与页数正确更新。
3. 输入并确认姓名关联的居民，已有卡号自动回填；无卡号时仍允许手填。
4. 已打印与已完成批次无法修改或删除。
