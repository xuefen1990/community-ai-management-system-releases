# v0.2.6 紧凑侧边栏底部设计

## 目标

将已登录工作台左侧底部的账户区从四个同等大小的操作块，调整为信息层级清晰、间距紧凑且不会遮挡文字的两行布局。该版本仅优化视觉和按钮编排，不改变授权、退出、刷新额度或检查更新的业务逻辑。

## 布局

账户信息仍位于顶部：头像、用户名、授权状态和主题切换按钮保持现有功能，压缩无效的上下留白。

操作区采用两层结构：

1. 第一行放置两个等宽的主要操作：`刷新额度` 与 `安全退出`。两者使用统一高度和间距，文字在可用宽度内保持单行，不再与图标重叠。
2. 第二行放置两个轻量控制：左侧为带盾牌图标的 `安全保护中` 授权同步入口，右侧为 `检查更新`。它们以文本型紧凑按钮呈现，而不是独立的大方块。

`安全保护中` 将继续保留原有的授权联网同步行为；`检查更新`、`刷新额度` 与 `安全退出` 也继续使用当前绑定的事件和标识，避免影响现有功能。

## 视觉规则

- 底部容器采用一致的内边距、圆角和 8px 左右的行间距。
- 主操作按钮高度约 40px；次级控制更轻量，并以一条横向信息栏呈现。
- 账户信息、主操作和次级控制之间保持明确层级，避免四个同等视觉重量的控件同时竞争注意力。
- 在现有桌面侧边栏宽度下，所有按钮文字均不换行、不截断、不与图标重叠；若容器变窄，次级控制可自然收缩但保留可点击区域。
- 继续兼容明暗主题，沿用现有配色变量和悬停、聚焦状态。

## 实现边界

修改渲染层的侧边栏 DOM 编排与样式，并保留既有按钮 ID、事件处理及可访问性标题。不会改动登录流程、授权判定、更新服务或应用数据。

## 验证与发布

- 更新侧边栏布局测试，确认四个功能入口仍在、行为标识未变，且紧凑布局类已生效。
- 运行渲染层相关测试及完整测试套件。
- 将应用版本更新为 `0.2.6`，构建可直接拖入“应用程序”文件夹的 Apple Silicon DMG，检查挂载内容后发布。
