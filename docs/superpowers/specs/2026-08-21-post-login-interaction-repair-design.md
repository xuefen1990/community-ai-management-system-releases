# 登录后页面交互修复设计

## 目标

用户完成本地登录后，工作台应立即可操作：登录层不应继续接收鼠标事件，旧版试用到期提示也不能遮挡或隐藏主界面。

## 方案

登录状态切换由一个小型界面状态函数统一处理。进入工作台时，该函数隐藏登录层、设置 `aria-hidden`，并禁用其鼠标事件；退出时执行相反操作。这样即使旧样式或动画残留，登录层也不能覆盖工作台操作。

永久授权兼容逻辑不再扫描页面文案或猜测父级节点。它只处理带有已知试用提示标识的遮罩节点；找不到明确节点时不修改任何容器。这样可避免误隐藏工作台或把页面置于不可点击状态。

## 验收

1. 登录成功后，登录层含有 `hidden`、`aria-hidden=true` 和禁用鼠标事件的状态。
2. 工作台恢复显示并可接收鼠标事件。
3. 旧试用提示的处理不会使用泛化的父级回退逻辑。
4. 渲染层测试覆盖上述状态与实现约束。
