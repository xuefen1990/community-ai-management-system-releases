# 社区AI管理系统 v0.2.3 手动登录与钥匙串记住密码设计

## 目标

修复应用启动后直接进入工作台、并露出旧版体验提示的问题。应用每次启动都显示登录页，预填上次选择记住的手机号与隐藏密码，用户手动点击登录后才可进入工作台。

## 版本与范围

- 以 `v0.2.3` 发布：`v0.2.2` 已公开，本次为登录体验的补丁修复。
- 不修改账号、授权、试用期限或工作台业务功能。
- 保留现有本地账号密码校验与离线授权流程。

## 启动与登录流程

1. 启动时始终保留登录页，不根据已记住账号自动展示工作台。
2. 后台仅读取登录表单的预填信息；不会调用登录接口，也不会创建登录会话。
3. 用户手动点击“登录进入工作台”后，才调用现有登录校验。
4. 校验成功且授权有效后，切换至工作台；无效授权仍在手动登录之后显示原有激活提示。
5. 旧版“免费体验已结束”遮罩不会在登录页或启动阶段显示。

## 凭据保存

- “记住登录”默认勾选。
- 勾选并登录成功时，手机号写入本地账号状态；密码使用 Electron `safeStorage` 加密后保存到 macOS 钥匙串保护的数据中。
- 下次启动读取并解密后预填：用户名显示，密码输入框保持 `password` 隐藏状态。
- 取消勾选并登录成功时，删除已保存密码；后续启动仅保留手机号。
- 点击“切换账号”立即清除预填密码和已保存的记住密码，回到空白登录表单。
- 任何无法解密或钥匙串不可用的情况都降级为仅预填手机号，并提示用户手动输入密码；不得阻断登录。

## 登录页布局

采用用户选择的 B 方案：

- 表单底部保留“记住登录”单行控件。
- 紧凑双按钮：左侧“切换账号”，右侧主按钮“登录进入工作台”。
- 辅助链接与安全提示缩小间距，避免底部按钮拥挤或失衡。
- 密码继续默认隐藏，并保留现有的显示/隐藏按钮。

## 组件边界

- 主进程新增受限的凭据存取服务，负责钥匙串加密、读取与删除。
- IPC 只提供“读取登录预填信息”和“清除记住密码”两个明确操作；渲染进程不直接访问钥匙串或持久化明文密码。
- 渲染层只负责表单预填、手动提交和“切换账号”交互。

## 验证

- 单元测试：保存、读取、清除和不可用时的凭据降级行为。
- 渲染测试：启动停留登录页、预填不自动登录、密码字段隐藏、紧凑双按钮存在。
- 手动检查：登录、取消记住、切换账号、永久授权和到期账号的流程。
- 运行完整测试套件，并构建/验证 v0.2.3 的 macOS DMG 后发布。
