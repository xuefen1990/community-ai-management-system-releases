# macOS 安装与更新修复设计

**日期：** 2026-08-20
**版本目标：** 0.1.2（Apple 芯片 Mac 测试版）

## 目标

修复 0.1.1 从 DMG 启动时无法检查更新的问题，并提供标准的 Mac 拖拽安装体验。安装完成后，用户从“应用程序”启动应用；应用启动时检查 GitHub Releases，仅在发现更新后提示，由用户确认后下载与安装。

## 安装体验

安装包采用 DMG：卷内包含“社区AI管理系统.app”和指向 `/Applications` 的“Applications”别名。用户将应用图标拖到 Applications 后，从“应用程序”启动。

应用不得把“从安装盘直接打开”视为已安装。若检测到运行位置不在 Applications，更新界面显示“请先将社区AI管理系统拖入应用程序后再打开”，不发起网络检查，不显示技术路径或原始错误。

## 更新配置与流程

构建时在应用包 `Contents/Resources/app-update.yml` 写入 GitHub 发布源：

- 发布者：`xuefen1990`
- 仓库：`community-ai-management-system-releases`
- 发布类型：正式 Release
- 本机更新缓存：独立于用户业务数据

该配置在对整个 `.app` 进行签名之前写入，确保打包后仍可被 `electron-updater` 读取。

已安装应用启动后：

1. 仅在打包环境且位于 Applications 中检查更新。
2. GitHub 返回较高版本时显示版本号与发布说明；不会自动下载。
3. 用户点“立即更新”后下载 ZIP；下载完成后用户再次确认“重启并安装”。
4. 任何检查、下载或安装错误均转成简短中文提示，保留当前应用与数据。

## 发布文件

- `社区AI管理系统-0.1.2-arm64.dmg`：首次安装使用。
- `社区AI管理系统-0.1.2-arm64.zip`：自动更新下载使用。
- `latest-mac.yml`：自动更新版本、文件名、大小和 SHA-512 校验信息。

Release 标题为 `v0.1.2`，说明包含安装方式与主要修复内容。0.1.1 保留为不使用的测试构建，不被覆盖。

## 验证

- 单元测试验证：未安装到 Applications 时不调用更新服务；内置更新配置可被打包脚本生成；下载始终需要用户操作。
- 构建后验证：DMG 同时含应用与 Applications 别名；`app-update.yml` 位于应用包 Resources；签名校验通过；更新清单版本、ZIP 文件名与 SHA-512 一致。
- 发布后验证：从 Applications 启动 0.1.1 时提示 0.1.2；点击“暂不更新”后，下次启动仍会提示。

## 范围边界

本次不处理 Apple Developer 正式签名和公证。0.1.2 为本机测试发布，首次打开可能仍需用户在 macOS 中右键选择“打开”。待具备 Developer ID 证书后，使用同一发布流程生成正式签名与公证版本。
