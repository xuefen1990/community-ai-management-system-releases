# 资金发放可视化工作台

根据本对话已确认的操作草图实施。新建/编辑批次采用一人一行表格：录入姓名时查询居民候选，唯一完整姓名可关联，重名必须按组别和身份证尾号人工选择。关联读取默认银行卡及模板配置的居民字段；无卡留空，不报警，不阻止打印。更换姓名必须清除旧居民关联及自动带入资料。居民资料和正式资金历史仍仅在发放完成后通过现有核对流程写入。

可复用同类历史批次的人员和版式。工资保留标准、清空月份供确认；杂工保留人员、清空本次用工日期/事项/工日/金额；承包费保留基础数量、清空本期单价。原批次不变。编辑支持撤销和草稿自动保存；不完整内容允许暂存但禁止直接打印、导出或完成发放。

打印预览保持左设置、中纸张、右页码。支持 A4/A5、横纵方向、四边距、字体字号、标题及眉头/签署字段、单元格对齐和换行、逐行高度和逐列宽度。行列支持数字调整与拖动；根据实测内容高度重新分页并重复表头，只呈现当前页。打印与预览共用纸张生成器，不打印按钮。修改默认仅属于批次，明确点击才更新模板或另存新模板，不开放自由合并单元格。

性能：姓名候选只输出有限条目，不为每行创建全居民列表；录入表分页显示，预览只渲染当前页；设置更新不重建整个弹窗。保存串行化，保存前读取最新数据库并检查目标批次是否被其他操作修改，保留其他业务数据。失败显示并允许重试，不提示虚假的“已保存”。

验收：重名、无银行卡、换人、导入、复用、自动/手工金额、撤销、草稿恢复、保存失败、锁定批次、模板快照、长文本分页、纸张方向、拖动、打印样式和发放完成同步回归。版本发布依项目 AGENTS.md，后端未确认前不得宣称可应用内更新。
