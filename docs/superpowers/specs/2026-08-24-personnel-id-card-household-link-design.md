# 身份证显示与一户一档户号直连修复设计

## 目标

修复 Excel 导入后身份证号已保存但界面显示为空的问题，并确保“一户一档”始终以户号作为成员关联键。

## 已确认的现状

- 本地人员数据已将身份证号保存到 `idCard`；旧界面部分位置仅读取 `id_card`。
- 一户一档的部分点击入口先读取身份证号，再定位人员；当旧字段为空时，入口无法打开对应户。
- 户号字段 `household_id` 已保存，是家庭成员关联的唯一依据。

## 方案

1. 建立人员字段兼容层：读取时统一解析 `idCard`、`id_card`、`identity_card` 与 `id_number`，以便已有档案立即显示身份证号。
2. Excel 导入时同时写入兼容字段，保证新导入数据可被旧界面和新模块读取。
3. 将一户一档的打开入口改为传递 `household_id`；成员、户主、人数和详情都从相同的精确户号查询结果中取得。
4. 户号仅去除首尾空格，不删除前导零，也不使用姓名或身份证号补全关联。

## 错误处理与验证

- 身份证缺失或格式异常时，表格显示为空值，但户号入口仍可打开同户成员。
- 对 `00123` 与 `123` 建立独立测试，验证不会混户。
- 对 `idCard` 和 `id_card` 各建立导入与显示测试。
- 验证点击一个存在两名成员的户号时，仅展示该户的两名人员。
