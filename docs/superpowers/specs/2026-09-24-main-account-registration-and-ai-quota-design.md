# 手机号注册、主账号数据归属与 AI 额度设计

## 目标与范围

新用户只填写手机号、密码、确认密码即可注册。注册成功后立即登录并进入工作台，账号默认为 30 天试用。新注册账号是主账号；它可按既定成员管理流程开通子账号。主账号和子账号共用一份永久有效、不自动重置的 AI Token 额度；每次使用记录实际操作人。主账号试用或正式授权到期时，子账号同时失去业务使用资格，续期后恢复原有数据和权限。

本次把新账号的业务数据、授权、子账号、AI 额度与 AI 共享记忆统一归属到稳定的主账号 ID。手机号是登录凭据，可修改；不能用手机号作数据归属键。注册、平台后台和业务鉴权不再要求填写或创建单位。已有单位名称可作为历史展示信息保留，不作为新账号的必填项或新数据隔离依据。

## 方案选择

1. 注册时暗中建立单位：改动较少，但后端继续依赖单位，与本次要求不符。
2. **以主账号 ID 为归属键（采用）**：新账号没有单位仍可获得独立工作区、共享额度和子账号；需要对旧数据做一次兼容迁移。
3. 新账号先使用本机数据、日后再转主账号：跨设备和同机多账号的数据归属不稳定，排除。

## 账号与注册

- 公开注册表单只有手机号、密码、确认密码。服务端检查手机号格式、唯一性和密码规则，密码仅存强哈希；重复号码与两次密码不一致分别给出明确中文错误。注册沿用现有公开接口限流和审计，不增加短信验证、姓名、单位或地区字段。
- `POST /auth/register` 创建启用的主账号，设置稳定的 `main_account_id = user.id`、30 天试用期，并初始化该主账号的共享工作区和默认 Token 额度。注册成功返回登录会话，客户端直接进入工作台；初始化失败时不能留下可登录但没有工作区或额度的半成品账号。重复请求不能重复赠送额度。
- 新账号的显示名称在未设置时采用脱敏手机号或“主账号”，日后可在个人资料中选填姓名。子账号仍由主账号输入姓名与手机号开通，初始密码、首次改密、模块权限和 AI 开关沿用已确认规则；每个子账号保存同一个 `main_account_id`。
- 授权检查从主账号读取试用、限期或永久状态。主账号停用或到期，子账号同时暂停；子账号单独停用只影响自身。平台管理员可调整主账号期限，不把子账号作为独立购买对象。

## 数据与额度

- 所有已登录业务读写必须解析出 `main_account_id`，服务端据此选择共享工作区并执行成员模块权限；找不到归属键时拒绝访问，不能退回本机公共数据。客户端缓存和工作区订阅也按主账号 ID 隔离，切换账号时清空旧快照。
- 额度记录和流水以 `main_account_id` 索引。主账号注册时只授予一次后台配置的默认额度；默认额度永久有效，用完后在线 AI 返回简短中文不足提示，不影响非 AI 业务。平台补充或调整额度仍记独立流水。
- 所有主账号及获准使用 AI 的子账号调用在线 AI，必须先校验同一主账号余额，再预留、结算或退回；不得因缺少旧单位 ID 走免计费路径。用量流水同时记录主账号 ID 和实际操作人 ID，主账号可看总量及分人用量，子账号只看自身明细与必要的共享余额。
- AI 对话和个人记忆仍按具体用户隔离；明确设为共享的记忆按主账号 ID 隔离。平台管理用的模型连通性测试与业务 AI 分开计量，不给普通账号开放免计费通道。

## 旧账号兼容迁移

- 对现有单位管理员，把其用户 ID 写为 `main_account_id`；原单位下的成员指向该 ID。原单位 ID、名称、审批记录等历史字段和记录保留，不删除或覆盖。
- 原单位工作区关联到对应主账号，数据、版本号与订阅连续保留。原额度的已授予、已使用、预留余额以及流水逐项关联到主账号；迁移不再次赠送默认额度。原 AI 使用明细和共享记忆保留来源及操作人。
- 迁移必须可重复执行且结果不变。发现一单位对应多个主账号、额度冲突或孤立成员时，记录具体异常并停止该记录的转换，不猜测归属或新建空工作区覆盖旧数据。上线前后校验主账号数、成员数、工作区版本、余额与流水总数。
- 新接口以主账号术语提供账号、成员、工作区和额度功能；旧 `/unit/` 路由在客户端过渡期间作为兼容别名，内部使用同一主账号鉴权，不另建一套数据。平台后台改为按主账号管理授权和额度；旧申请记录只供历史查询，不再作为新注册入口。

## 页面与交互

登录页入口改为“手机号注册”。注册成功直接进入工作台，显示试用剩余天数和主账号共享 Token 余额。成员管理页不要求单位名称；主账号新增成员、分配权限和关闭 AI 的操作保持简单。平台后台用户列表以手机号、账号类型、试用/授权状态、成员数、额度摘要为主，不要求单位字段。

## 验证与交付

- 覆盖注册成功自动进入工作台、重复手机号、密码不一致、注册重试不重复赠额、试用到期及续期、成员继承期限和权限。
- 覆盖两名主账号同机/跨机数据互不可见；主账号与其子账号共享同一工作区和额度；子账号 AI 关闭后拒绝调用；额度扣减、失败退回及流水操作者正确。
- 用旧数据样本验证迁移前后工作区内容、版本、成员关系、额度余额与流水不变；验证异常归属不会静默迁移。确认平台管理员仍可按主账号调整期限与额度。
- 日常修改先用 `npm run dev` 和独立开发数据验证，不自动打包正式应用。后端改动按项目约定核对差异、运行验证、仅同步本次后端文件到 ECS，并检查服务与实际入口；无法连接时如实报告未部署部分。

## 不在本次范围

短信验证码、在线支付、子账号单独购买额度、多个同权主账号、正式应用打包发布、删除历史单位记录，以及与注册和额度归属无关的业务界面改造。
