# 单位申请表单排版设计

## 目标

优化登录页内的“开户注册申请”表单，使单位管理员申请和邀请码加入单位在常见桌面窗口高度下都具有清晰层级、可见操作按钮和舒适间距。

## 范围

- 仅调整 `panel-register`（开户注册申请）界面。
- 不改变申请接口、字段、审核流程或登录页的普通账号登录功能。

## 布局

- 保持单页填写：申请类型、申请人资料和单位资料在同一个表单中完成。
- 标题下放置横向申请类型选择，默认“申请成为单位管理员”；选择邀请码加入单位时，仅显示邀请码字段。
- 姓名、手机号、单位名称和地区使用单列；密码与确认密码在宽屏下并列，在窄屏下自动改为单列。
- 表单内容区按登录卡片可用高度滚动；标题和底部操作区不随字段滚出可视区域。
- 底部固定显示“返回登录”和“提交申请”，主操作按钮更突出。

## 视觉规则

- 降低标题区的空白，字段间距统一为适中的 14–16px。
- 标签、输入框和提示文本采用现有绿色主题与圆角、边框规范。
- 表单滚动条保持低存在感，不遮挡字段和按钮。

## 验收

- 在常见 16:9 桌面窗口中，用户无需缩放即可看到标题、申请类型和固定操作按钮。
- 单位管理员申请的全部字段可通过内容区滚动填写，不会被卡片底部裁掉。
- 邀请码申请切换后字段显示正确，提交逻辑保持不变。
- 小窗口下页面仍可滚动并完成提交。
