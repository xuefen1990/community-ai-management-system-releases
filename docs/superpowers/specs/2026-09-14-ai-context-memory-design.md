# AI 连续对话与长期记忆设计

## 目标

修复模型连接测试成功但正式查询回退的问题，让 AI 助理只读取当前问题需要的本机资料；同时提供跨重启连续对话、个人记忆、单位共享规则、主动追问和可管理的记忆记录。

## 调用流程

1. 后端模型只负责理解和组织语言，不接收整套居民数据库。
2. 桌面端先从最近对话和记忆中补全指代，再按姓名、组别、年度和业务类型在本机精确检索。
3. 信息不足或同名时直接询问需要补充的字段，不猜测。
4. 查询结果只把必要字段交给模型，动态业务数据每次从台账重新读取。
5. 修改操作继续沿用当前确认与撤销机制。

## 记忆范围

- 个人记忆：按登录账号隔离，可记录称呼、表达习惯和常用查询方式。
- 单位规则：按单位共享，新增前需要明确确认。
- 身份证、电话、银行卡和实时金额不写入长期记忆。
- 所有记忆均可查看和删除。

## 故障处理

- 禁止模型请求全库资料，相关事实集合设置条数和字符上限。
- DeepSeek 对话关闭深度思考并限制回答长度，减少超时和 Token 消耗。
- 在线调用失败时显示经过脱敏的中文原因，同时继续保留能由本机规则完成的查询。
