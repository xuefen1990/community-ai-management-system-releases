# 公文拟写 A4 预览、字体应用与打印预览设计

日期：2026-08-16  
状态：已确认方案 A，待实施

## 1. 背景

当前公文拟写页面已经支持正文编辑、字体字号选择和打印，但实际使用中存在三个问题：

1. 右侧正文以接近实际字号直接铺开，视觉上过大；公文变长后页面整体滚动，左侧补充要求区域也随之离开视野。
2. 字体选择器虽然能够切换选项，但字体没有稳定作用到用户预期的正文范围，系统字体回退也会让部分字体看起来没有变化。
3. “打印”会直接调用打印流程，缺少在打印前查看真实 A4 分页、页边距和落款位置的预览步骤。

## 2. 目标

- 左侧 AI 公文助手在桌面窗口中保持可见，右侧公文独立滚动。
- 右侧默认以“适合页面”的比例完整显示首张 A4，保留“适合宽度”“100%”和加减缩放。
- 字体修改稳定作用于选区或全文，并保存全文默认字体供下次拟写使用。
- 点击打印后先进入真实 A4 打印预览，确认后再进入系统打印。
- 编辑、导出和打印共用同一份版式参数，避免结果漂移。

## 3. 非目标

- 本次不重做 AI 生成逻辑、历史记录或报告/合同互通逻辑。
- 本次不引入在线字体下载；优先使用 macOS 已安装的中文字体及明确的兼容回退。
- 编辑区不强制模拟打印机的硬件不可打印边缘。具体打印机纸盒、双面、颜色等仍由 macOS 系统打印窗口决定。

## 4. 已选方案

采用方案 A：固定高度工作区、左右独立滚动、可缩放 A4 编辑画布、字体作用范围修复，以及打印时生成真实分页预览。

没有采用仅缩小字体或仅让左栏吸顶的简化方案，因为它不能解决真实版式和打印预览问题。也不在每次输入时持续生成 PDF，以免影响正文编辑流畅度；仅在用户点击“打印预览”时生成一次真实分页结果。

## 5. 页面布局与滚动

### 5.1 桌面布局

- 公文工作区高度限制在当前应用可视区域内，不再由正文内容把整个页面向下撑开。
- 左侧 AI 公文助手是独立面板。正常情况下整栏保持不动；当窗口高度过小时，仅左栏内部允许滚动。
- 右侧由固定工具栏、独立预览滚动区和固定状态/操作栏组成。
- 滚轮位于右侧时，只滚动 A4 预览内容，左侧输入框和重新生成按钮保持可见。

### 5.2 A4 预览缩放

- 编辑画布继续使用真实 A4 尺寸和毫米页边距作为版式基准，屏幕显示只改变缩放比例，不改变文档字号和导出结果。
- 默认模式为“适合页面”：根据右侧可用宽高计算比例，完整显示首张 A4。
- “适合宽度”以右侧可用宽度计算比例，文字更容易编辑，较长内容在右侧内部滚动。
- “100%”显示实际 CSS 尺寸；加减按钮以固定步长调整，并限制合理的最小、最大比例。
- 窗口尺寸变化时，“适合页面”和“适合宽度”自动重新计算；手动比例保持用户选择。
- 状态栏显示当前缩放比例。缩放只是视觉状态，不写入公文版式偏好。

### 5.3 小窗口兼容

- 当窗口宽度不足以并排展示时，沿用单列响应式布局，避免为了固定左栏而压缩正文到不可用宽度。
- 桌面常用宽度下必须保持左右双栏和右侧独立滚动。

## 6. 字体应用规则

### 6.1 作用范围

- 编辑器内存在当前可见文字选区时，字体或字号只作用于该选区。
- 没有有效文字选区时，字体或字号作用于全文，并更新公文版式的正文默认值。
- 已失效、已折叠或属于其他控件的旧选区不得被误当成当前选区。
- 全文修改时清理与本次属性冲突的旧行内覆盖，确保用户能立即看到变化；不影响加粗、列表、对齐等其他格式。

### 6.2 字体映射

字体选项使用按平台排序的字体族，而不是只依赖一个可能不存在的英文名称：

- 仿宋：优先 `FangSong` / `STFangsong`，不可用时回退到 `Songti SC` 和衬线字体。
- 宋体：优先 `Songti SC` / `STSong`，再回退到衬线字体。
- 楷体：优先 `Kaiti SC` / `STKaiti`，再回退到衬线字体。
- 黑体：优先 `Heiti SC` / `STHeiti`，再回退到 `PingFang SC` 和无衬线字体。

实施时先读取当前 macOS 的可用字体名称并据此校准顺序。不下载、不捆绑来源不明或授权不明确的字体。

### 6.3 默认偏好

- 全文字体、字号、版式或行距变更继续保存到“我的写作偏好”。
- 新建下一份请示、报告或合同都以最后一次保存的全文设置为默认值。
- 仅对局部选区的格式修改不覆盖下次新文档的全文默认值。

## 7. 打印预览流程

### 7.1 用户流程

1. 用户点击“打印预览”。
2. 系统先保存当前编辑内容和版式。
3. 应用使用与导出/打印相同的 HTML、字体、A4 页边距和行距生成分页预览。
4. 打开独立打印预览界面，展示真实 A4 页数和分页结果。
5. 用户可查看各页、缩放预览或关闭返回编辑。
6. 用户在预览中点击打印后，再进入 macOS 系统打印窗口设置打印机、份数、单双面等。

### 7.2 真实性保证

- 打印预览由 Electron 的打印排版引擎按 A4 生成 PDF/等价分页结果，不使用编辑区截图。
- 预览和最终打印读取同一个已保存版本及同一套 `printableHtml` 版式参数。
- 预览清楚显示纸张边界、分页、页边距、标题、抬头、正文、落款和日期。
- 打印机的物理不可打印边缘与驱动选项只能在选择具体打印机后由系统提供，应用预览不伪造这些信息。

### 7.3 临时文件与失败处理

- 如使用临时 PDF，只写入系统临时目录，预览窗口关闭或应用退出后清理；不写入用户档案或历史记录。
- 生成预览失败时保留当前正文，显示明确错误，并允许用户返回编辑重试。
- 打印取消不视为失败，也不会重复保存版本。

## 8. 数据与模块边界

- 渲染层负责：缩放模式、缩放比例、左右滚动状态、字体作用范围判断和打印预览入口。
- 主进程导出服务负责：使用已保存公文生成打印 HTML、真实分页预览和系统打印。
- IPC 只传递公文标识、已确认的版式参数或预览结果引用；不把 API 密钥或其他系统设置传入预览页面。
- 现有 Word/PDF 导出继续使用同一份布局归一化逻辑。

## 9. 验收标准

### 布局

- 在常用桌面窗口尺寸下滚动长公文时，左侧补充要求和按钮保持可见。
- 右侧首次进入默认完整显示一张 A4，且可切换适合宽度、100%与手动缩放。
- 缩放不会改变保存、Word、PDF或打印中的实际字号。

### 字体

- 未选中文字时从仿宋切到黑体、楷体或宋体，全文立即出现可辨识变化。
- 选中文字时只改变选区，未选中的正文保持原字体。
- 刷新或重新进入当前公文后字体保持；新建公文继承上次全文默认字体和字号。

### 打印

- 点击打印先出现 A4 打印预览，而不是立即打印。
- 多页公文在预览中显示正确页数、分页、页边距和落款位置。
- 从预览进入系统打印后，纸张版式与预览一致。
- 关闭或取消预览不会丢失正文和手动修改。

## 10. 测试范围

- 渲染层单元测试：缩放模式计算、选区/全文字体应用、偏好保存、打印预览按钮流程。
- 主进程单元测试：预览生成参数、A4 配置、打印调用、失败和取消处理、临时文件清理。
- IPC 与 preload 合约测试：新增预览能力只暴露规定参数。
- 回归测试：AI 生成、补充重新生成、手动编辑、历史版本、Word/PDF 导出。
- 手工视觉测试：普通窗口、较矮窗口、长公文、多页公文，以及仿宋/宋体/楷体/黑体切换。
