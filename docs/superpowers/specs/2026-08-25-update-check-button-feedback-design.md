# 更新检查按钮反馈设计

## 目标

让侧栏的“检查更新”按钮在可操作、检查中和检查完成后都呈现明确且稳定的视觉状态，不再遗留“检查中”文字。

## 交互规则

- 默认状态显示“检查更新”，按钮大小和布局固定。
- 鼠标悬停或键盘聚焦时，按钮上浮 2 像素、主色加深并增加柔和阴影；按下时恢复到原位。
- 点击后立即禁用按钮，显示旋转更新图标和“检查中”，避免重复发起检查。
- 检查完成后，无论结果为无更新、发现更新、服务不可用、安装条件不足或出错，均恢复默认文案、图标和可用状态。
- 检查结果仍通过现有提示或更新弹窗呈现；按钮不承载结果文字。
- 在系统启用“减少动态效果”时，取消位移动画和旋转动画，保留颜色与状态文字变化。

## 实现边界

- 仅调整 `app/src/renderer/js/update-ui.js` 与关联样式，不改动更新服务协议或后端接口。
- 使用一次统一的状态收尾逻辑，避免分支漏恢复。

## 验证

- 自动检查按钮加载状态、禁用行为、统一恢复逻辑和样式选择器。
- 运行桌面端现有测试套件，确保更新弹窗与本地授权界面不受影响。
