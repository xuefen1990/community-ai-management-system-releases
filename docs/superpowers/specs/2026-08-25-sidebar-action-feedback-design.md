# 侧栏操作区统一反馈设计

## 目标

统一左下角账号操作区的按钮反馈，移除不具备操作含义的“安全保护中”按钮，并降低退出操作的误触风险。

## 布局

账号信息下方保留四项操作，采用两列两行网格：

1. 第一行：`刷新额度`、`检查更新`。
2. 第二行：`成员与权限`、`安全退出`。
3. 删除“安全保护中”按钮及其占用空间。

这满足用户确认的 A 方案：检查更新位于右上，安全退出位于右下；四个按钮尺寸一致、间距一致。

## 交互

1. 四个保留按钮均有悬浮反馈：轻微上浮、边框与背景强化、匹配功能语义的阴影。
2. 所有按钮均有按下反馈，短暂回落并轻微缩放。
3. 刷新额度、检查更新、成员与权限使用品牌绿色系的悬浮色彩。
4. 安全退出使用浅红色悬浮色彩，以提示退出语义但不使用突兀的常驻红底。
5. 检查更新在请求期间仍显示旋转图标和“检查中”，无论成功或失败均恢复可交互的“检查更新”。
6. 成员与权限保留现有点击入口；悬浮、键盘聚焦和点击按下均有即时反馈，点击后仍打开成员与权限管理界面。
7. 系统启用“减少动态效果”时，保留颜色和焦点反馈，但停用位移与旋转动画。

## 实现边界

除侧栏调整外，新增独立的“成员与权限”管理页；不改变单位管理员统一控制成员有效期的授权规则。

## 新成员与权限页

1. 仅单位管理员可看见并使用侧栏的“成员与权限”按钮；普通成员不显示该管理入口。
2. 新页面替代并删除旧的成员管理入口和旧界面，不复用旧界面的布局或交互。
3. 页面分为三个清晰区域：
   - **成员**：显示姓名、账号、状态、最后登录时间和已分配权限；管理员可编辑权限、重置为空权限、停用或恢复成员。
   - **待审核申请**：显示邀请码加入的待审核账号；管理员可通过、拒绝，并在通过时分配初始权限。
   - **邀请码**：可新建邀请码、查看有效期和使用次数、停用不再使用的邀请码。
4. 页面顶部显示本单位统一授权状态；成员的有效期只读且自动与单位管理员同步。
5. 成员停用为可恢复状态，不做不可逆的账号删除；保留审核和权限变更记录。

## 数据和错误处理

1. 继续使用已有成员、申请、权限和邀请码接口；补充成员停用/恢复与最后登录时间的数据支持。
2. 每次修改成功后刷新当前列表；失败时保留原列表并明确显示失败原因。
3. 非单位管理员访问相应接口时后端继续拒绝，前端不显示管理入口。

## 验收

1. 页面上不再显示“安全保护中”。
2. 四个保留按钮按 2×2 顺序显示，窄侧栏下文字不溢出。
3. 鼠标悬停每个按钮都能看到对应反馈；键盘聚焦仍有清晰焦点框。
4. 更新检查按钮在检查期间不可重复触发，结束后恢复默认文案与状态。
5. 单位管理员点击成员与权限后打开新管理页，成员、申请、邀请码均可正常操作。
6. 普通成员看不到单位管理入口，也不能调用管理接口。
7. 原有成员管理入口和旧界面已删除，停用成员仍可恢复。
8. 现有侧栏、账号和更新相关自动测试通过，并新增成员管理页和权限保护测试。
