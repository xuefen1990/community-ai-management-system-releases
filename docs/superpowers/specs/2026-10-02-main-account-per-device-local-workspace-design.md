# 主账号逐电脑独立本地工作区设计

日期：2026-10-02  
状态：用户已确认

## 行为规则

- 主账号在任意电脑联网登录后，直接使用该电脑按主账号身份隔离的本地业务工作区。首次使用且无数据时显示空台账，不要求扫描或连接另一台主电脑。
- 不同电脑的业务数据彼此独立，不经云端或登录动作自动复制、合并或同步。界面明确标明当前电脑的数据来源，避免把另一台电脑的空库误认为原记录丢失。
- 子账号仍须连接明确选择的局域网共享电脑。没有连接或离开局域网时业务不可用，不能退回云端或子电脑本地副本。
- 主账号在某台电脑开启局域网共享时，该电脑正在使用的本地工作区就是子账号读写的数据源；主账号和子账号修改同一份数据，不生成两份分叉副本。共享服务可在主账号退出应用账号后随应用后台运行。
- 当前 Mac 上的旧云端业务数据只能通过显式迁移入口导入并核对。主账号在其他电脑登录不会触发旧云端数据复制。若目标已有非空业务数据，迁移必须阻止覆盖并提示先处理冲突。云端旧副本在完整核对前保留。

## 实现边界

- 登录后根据账号角色选择工作区：主账号绑定本机工作区；子账号绑定经身份核对的局域网地址。账号切换时清除内存快照，并阻止跨主账号读取本机数据。
- 本机工作区读写、附件、AI 历史和共享服务使用同一账号归属及同一存储路径。仅登录验证、权限、模型调用和通用设置访问云端。
- 设置页分别显示“当前电脑本地数据”“已开启共享”或“子账号连接的电脑”，并提供显式迁移与共享操作。缺少连接的提示只对子账号出现。
- 验证主账号在两台电脑分别得到独立数据，子账号只能访问所选共享电脑，切换账号和断连时没有业务数据泄漏；旧云端迁移失败时来源数据不被清理。
