# 地力补贴待处理项批量导入居民档案设计

**日期：** 2026-09-01  
**状态：** 已确认，待实现

## 目标

在年度地力补贴的“待处理项”中，让管理员可以勾选多条记录、预览处理结果，并将可安全确认的数据批量写入居民档案。导入后，补贴记录与居民档案自动关联；居民档案能按资料类别查看银行卡和补贴历史。

## 范围

- 待处理清单增加单条勾选、全选当前页、全选查询结果，以及取消选择。
- 对已选择的记录提供“批量导入居民档案”。
- 在真正写入前显示只读预览：新建档案数、补充档案数、待人工处理数，以及每条记录的处理结果。
- 成功导入的记录自动关联到居民档案，待处理数量随即重新计算。
- 居民档案新增“联系与银行卡”“补贴与发放记录”“来源与更正记录”资料标签页。

本次不改变补贴金额、面积、标准或既有补贴主表内容；不提供批量覆盖已有居民字段。

## 识别与写入规则

1. 身份证号是唯一自动匹配依据。身份证号会去除空格并统一大写后比较。
2. 找到唯一同身份证居民，且补贴记录的姓名、组别与其档案一致：关联该居民，并仅填写该居民为空的字段。
3. 找不到同身份证居民：新建一条居民档案，写入补贴表中实际存在的信息。
4. 同一身份证对应多条居民档案，或同身份证下姓名、组别不一致：不写入、不关联，保留为“待人工处理”。
5. 已有居民中的姓名、身份证、组别、银行卡、开户行、手机号均不被本功能覆盖；只有目标字段为空时才补充。
6. 无身份证号的补贴记录不能自动导入，保留为待人工处理。

## 字段与资料标签页

### 基本信息

继续保存并显示姓名、身份证号、村（居）、村民组等基本身份资料。

### 联系与银行卡

显示及维护手机号、开户行、银行卡号。批量导入只补充空白项；银行卡同时写入现有的银行卡资料结构，并设为默认银行卡仅当该居民此前没有默认卡时。

### 补贴与发放记录

每次成功导入都追加一条年度地力补贴来源记录，至少包括：补贴年度、台账标识、面积、补贴标准、补贴金额、导入时间。相同的“年度 + 台账 + 补贴记录”重复执行导入时不重复追加。

### 来源与更正记录

记录本次资料来自年度地力补贴台账、导入时间和本次实际补充的字段；后续对居民或补贴主表的更正仍沿用系统既有更正记录。

## 操作流程

1. 管理员在待处理项清单勾选记录，可跨页保留选择。
2. 点击“批量导入居民档案”。系统只计算预览，不写入数据。
3. 预览按“可新建”“可补充并关联”“需人工处理”分组展示，并提供返回清单和确认导入。
4. 管理员点击确认后，系统仅写入预览中可安全处理的记录；人工处理项保持原状。
5. 保存成功后，弹出结果摘要并返回待处理清单。已成功记录不再显示在待处理项中。

## 失败处理与数据安全

- 预览和确认之间重新按当前数据库校验，防止旧预览覆盖新数据。
- 写入失败时，不显示“已导入”；界面保留选择，管理员可重试。
- 单条异常不阻塞其余安全记录，但异常条目必须出现在结果中并保留原始补贴数据。
- 所有新增和补充操作均带来源记录，方便后续追溯。

## 验证

- 模型测试：新建、补空白、冲突、重复身份证、无身份证、重复导入不重复写补贴历史。
- 界面测试：跨页选择、全选、预览、确认、待处理数量刷新与标签页显示。
- 回归测试：原有单条关联、主表编辑、查询分页、补贴五张表导出仍可使用。
