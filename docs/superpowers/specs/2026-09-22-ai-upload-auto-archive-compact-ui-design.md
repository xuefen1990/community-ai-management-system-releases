# AI 上传自动归档与紧凑界面设计

## 目标

明确可识别的营业执照、法人证书和资格证书在上传后自动整理到电子档案柜；AI 对话区仅展示简洁结果和图片缩略图，不再反复显示 Token 用量。

## 处理规则

- 文件名或识别文字明确命中“营业执照”“统一社会信用代码”“法人资格证书”等特征时，归类为“营业执照”。
- “营业执照”分类不存在时自动创建并归档，操作写入记录且可撤销。
- 判断不可靠时继续留在“待归档”，由工作人员选择分类，系统不猜测。
- 同一文件再次上传时重新计算分类建议，避免旧的待归档结果长期不更新。

## 界面

- 图片在对话区显示为固定尺寸缩略图，点击后使用现有图片查看器显示原图。
- 上传结果只展示文件名、识别类型和归档状态；不再自动追加冗长任务步骤或预填提问。
- 归档成功后重新加载电子档案柜，使新分类和数量立即显示。
- AI 对话顶部、单条回复和任务卡不显示 Token；系统设置继续保留单位额度与用量统计。额度耗尽时仅提示无法继续使用和联系管理员。

## 验证

- 测试营业执照图片首次上传时自动创建分类并归档。
- 测试普通缺失分类仍等待人工确认。
- 测试聊天区不存在 Token 用量文本，缩略图尺寸受到限制。
- 运行项目全量测试和开发模式热更新检查。
