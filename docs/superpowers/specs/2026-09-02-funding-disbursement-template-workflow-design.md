# 资金发放模板、准备发放与打印预览设计

## 目标

资金发放中心提供可长期复用的发放模板。工作人员以“选择模板—选择人员—准备发放—打印预览—留档查询”的方式完成工资、杂工、补贴、承包费及其他费用的发放表制作。

系统应保持类似 Excel 的表格编辑体验，但以居民档案唯一编号、计算规则和打印版本保证人员与金额准确可追溯。

## 模板管理

每个发放模板保存以下配置：

1. 基本信息：模板名称、适用类型、默认表头、编制单位与单位。
2. 字段配置：字段名称、数据类型、是否必填、列顺序与列宽。数据类型支持文字、日期、数量、金额和下拉选项。
3. 居民联动：模板字段可从居民档案带入姓名、身份证号、组别、联系电话、银行卡号、开户行、人口和确权面积等资料。
4. 计算规则：支持数量乘单价、金额减扣除款等规则。每项同时保存自动计算金额和实发金额。
5. 打印配置：纸张（A4 或 A5）、每页人数、表头、合计栏、金额大写、签字栏以及默认审批人、制表人、经办人。

模板本身是默认格式。批次中可临时调整字段、版式、标题和签字信息；临时调整只影响当前批次，也可以另存为新模板。

## 新建与准备发放

新建批次时，用户先选择发放类型和模板，再填写本次发放名称、期间、日期、单位、资金来源及备注。

选择居民后，系统根据模板自动带入居民资料。批次记录保存居民档案唯一编号及当时的资料快照，后续居民资料变更不影响历史批次。

固定人员模板可带出固定名单；杂工与其他临时发放模板允许手工新增临时人员，并明确标记为临时人员，不写入居民档案。

### 同名确认

系统不能只按姓名绑定居民。检索到同名人员时，必须显示组别、身份证号后四位与银行卡后四位，并要求操作人员选择具体档案。未确认的同名人员不能加入发放批次。

### 金额规则

系统按模板计算自动金额。用户可以修改实发金额，但必须填写修改原因。自动金额、实发金额、修改原因和时间均随批次保存。

在“准备打印”前，系统检查：银行卡缺失、同名未确认、同一居民重复加入、金额为零或异常、人工修改金额未写原因等问题。

## 预览、打印和留档

打印前先生成真实纸张比例的预览：

- A5 模板默认每页约 10 人，并自动分页；
- A4 模板用于承包费、补贴等宽表；
- 预览展示页码、人数、表头、合计、金额大写和签字位置；
- 当前批次可临时调整纸张、每页人数、列宽、标题和签字人；
- 预览确认后可打印、导出 Excel 或导出 PDF。

打印后保存不可变的打印版本。批次状态为：草稿、准备打印、已打印、已发放、已作废或已更正。已发放批次不能直接编辑；更正或作废必须记录原记录、变化内容、原因、时间和操作人。

## 查询与安全规则

模板、草稿、打印版本和发放记录可按年度、模板、发放类型、姓名、组别、身份证号、银行卡号、状态与金额查询。

模板变更不会改写历史批次。居民资料不因批次编辑而自动改写；银行卡等资料冲突必须走居民档案核对流程。

## 验证

实现完成后，测试应覆盖：

1. 模板字段、居民联动字段和计算规则的保存与应用；
2. 自动金额、人工修改金额和修改原因；
3. 同名居民的人工确认和唯一编号绑定；
4. 固定人员与临时人员两种来源；
5. A4/A5 预览、自动分页、临时版式和另存模板；
6. 打印版本快照、状态流转、更正和作废留痕；
7. 历史批次不受模板或居民档案后续变更影响。
