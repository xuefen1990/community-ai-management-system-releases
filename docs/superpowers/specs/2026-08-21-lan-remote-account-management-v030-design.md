# v0.3.0 局域网账号与授权管理设计

## 目标

将新注册账号、登录会话和授权状态统一由局域网后端管理。桌面端用户注册后，管理员可立即在后端管理后台查看账号，并设置试用、限期或永久授权，以及启用或停用账号。

## 部署方式

后端部署在局域网内的一台主机上，监听局域网可访问的地址和端口。管理员账号、口令、JWT 密钥与数据库路径只保存在该主机的私有 `.env` 配置中；这些值不写入代码、测试、文档或 Git 提交。

后端管理员页面继续位于 `/admin/`，仅超级管理员可登录。局域网测试使用 HTTP；在未来公网部署时必须改用 HTTPS。

## 桌面端体验

登录页新增“账号服务器地址”入口：

1. 用户首次使用时填写后端地址，例如 `http://192.168.x.x:3000`，并可执行连接测试。
2. 地址校验通过后保存在当前电脑的应用私有配置中；后续启动自动使用该地址。
3. 注册和登录均请求该后端。后端不可访问或地址无效时，显示明确错误且不创建本机孤立账号。
4. 已成功登录的用户仍按现有方式手动登录；记住登录信息仅用于预填，不自动进入工作台。

## 账号与授权数据流

1. 桌面端注册提交手机号、密码和设备标识至后端。
2. 后端保存密码哈希、账号资料、设备绑定及初始试用授权，并写入注册审计日志。
3. 管理员在 `/admin/` 的账号管理页可检索账号、查看注册信息、调整授权类型和限期授权的到期时间、启用或停用账号、重置密码。
4. 桌面端在登录后、每次启动授权检查时读取后端授权状态。管理员修改授权后，用户下次登录或重新打开应用即可按新状态生效。
5. 后端是新账号的唯一授权权威来源；既有本机账号不自动上传或迁移。

## 实现边界

- 复用已有远程认证服务、后端注册/登录/授权 API 和管理员后台，补全桌面端可配置服务器地址、健康检查、持久化和错误提示。
- 保持当前 IPC 认证接口和登录页的手动登录语义，避免影响其他工作台功能。
- 管理员后台继续使用既有账号管理界面，不新增多管理员或角色体系。
- 不在 v0.3.0 中迁移历史本机账号，也不提供公网部署、证书签发或生产数据库迁移。

## 安全与错误处理

- 服务器地址只允许 `http` 或 `https` URL；局域网模式提示仅应在可信网络使用。
- 管理员口令只存在服务器 `.env`；后端返回的账号信息不含密码、哈希或模型密钥。
- 认证令牌保存在应用私有状态；记住密码继续使用系统安全存储。
- 网络错误、服务不可达、401、账号停用、授权到期和校验失败均显示可理解提示；错误时不回退为本地注册。

## 验证与发布

- 后端测试覆盖注册后管理员可查询账号、修改限期日期或永久授权、停用账号以及非管理员拒绝访问。
- 桌面端测试覆盖服务器地址校验和保存、连接失败不创建本机账号、远程注册/登录与授权读取。
- 局域网联调：一台主机运行后端，另一台电脑注册；后台可见该账号，修改授权后重新登录桌面端验证状态。
- 完成后发布 v0.3.0 的 Apple Silicon 可拖拽 DMG，并附带局域网后端启动说明。
