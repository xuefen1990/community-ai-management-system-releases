# v0.2.0 底部栏紧凑排版设计

## 目标

将桌面端侧边栏底部的账号与操作区域调整为紧凑、稳定的布局，避免“刷新额度”和“安全退出”等操作文字换行，同时保留现有全部功能。

## 范围

- 账号、授权状态与主题切换仍位于底部信息行。
- 操作行包含刷新额度、安全退出、隐私说明与检查更新。
- 更新版本号为 `0.2.0`。

## 布局方案

采用已确认的 A 方案：

- 操作区使用单行等宽网格，统一 36px 高度与 6px 间距。
- 所有操作按钮使用不换行文本、居中图标与文本、统一圆角和内边距。
- 窄窗口通过缩小按钮字体与图标间距维持单行；不隐藏操作、不改变交互。

## 实施边界

- 只调整侧边栏底部相关的 HTML/CSS，并更新应用及锁定文件的版本号。
- 不变更登录、授权、隐私说明或软件更新的业务逻辑。

## 验证

- 现有更新界面测试通过。
- 检查 HTML 中四项操作仍可被现有脚本定位。
- 检查 CSS 语法、版本元数据一致性和改动差异。
