# 系统设置分类切换修复设计

## 目标

修复“系统设置”页面上方分类按钮无法切换内容的问题。用户点击“菜单显示”“局域网共享”等分类后，应立即看到对应设置，并清楚知道当前所在分类。

## 范围

- 保留“基础设置”为进入页面时的默认分类。
- 让八个现有分类按钮统一驱动内容切换：基础设置、菜单显示、局域网共享、字典管理、专项类别、操作日志、账号授权、智能助理。
- 同步更新按钮的当前选中状态，并仅显示属于当前分类的设置卡片。
- 不修改任何设置数据、保存逻辑、备份逻辑或授权逻辑。

## 方案

在设置页面初始化时注册一个专门的分类切换控制器。它从按钮的分类标记读取目标分类，点击后切换按钮选中状态和对应设置卡片的可见性。控制器仅依赖页面既有的分类标记，因此新增同类设置卡片会自动按标记参与切换。

若页面中缺少分类按钮或设置卡片，控制器安全退出，不影响其他页面功能。

## 验证

- 自动测试覆盖八个分类的点击切换：目标分类内容可见，其他分类内容隐藏，当前按钮高亮。
- 保留并验证基础设置首次打开时仍显示。
- 运行现有渲染端测试，确保设置页其他功能未受影响。
