# 专项人员档案字段导入设计

## 目标

将专项 Excel 表中的业务字段保存为可查询、可维护的专项档案，而非只给统一人员档案追加一个身份标签。党员表导入后自动进入“党员与支部台账”；退役军人、低保等其他专项表按相同模式保存各自信息。

本设计同时依赖已确认的表头自动识别和无效行过滤规则：标题、基础信息行与底部合计/签字等内容不参与导入。

## 导入模型

每条有效 Excel 数据同时写入两层记录：

1. **统一人员档案**：姓名、身份证号、性别、民族、出生日期、学历、联系电话、村民小组、住址等通用字段；继续以身份证号为唯一合并凭证。
2. **专项档案**：以“专项身份 + 身份证号”为唯一键保存对应业务字段，并与统一人员档案关联。再次导入时仅以非空值补充或更新同一专项档案，不创建重复记录。

未被预置字段匹配的列保存到专项档案的“其他信息”中，保留原列名和值，避免丢失来源表中的业务数据。

## 字段模板与映射

导入窗口根据自动识别或手动选定的专项标签显示对应映射项，并预选表头别名匹配的列；用户仍可在每个下拉框中手动调整或选择“不导入”。

### 党员

- 通用字段：姓名、组别、身份证号、性别、民族、出生日期、学历、联系电话、家庭住址。
- 专项字段：所属党组织/党支部、加入党组织日期、转为正式党员日期、党员阶段或类型、党内职务。
- 保存后自动新增或更新 `partyMembers` 台账记录；“入党时间”优先显示加入党组织日期。

### 退役军人

- 通用字段同步到人员档案。
- 专项字段：服役部队、入伍日期、退役日期、军衔/职务、优待证号、安置或就业状态。

### 低保、特困、残疾、监测户等

- 低保/特困：保障类别、认定日期、保障金额、家庭人口、致困原因。
- 残疾：残疾类别、残疾等级、证件号码、发证日期。
- 监测户/脱贫户：识别日期、风险类别、帮扶责任人、帮扶状态。
- 其余已支持身份同样保留所有未匹配列为“其他信息”，后续可逐步增加专属字段模板，无需重新导入历史表格。

## 用户反馈与安全

- 预览摘要显示识别到的表头行、有效人员数与自动忽略的无效行数。
- 摘要同时显示本次会写入的专项档案类型和字段数。
- 身份证号缺失、格式或校验不通过的行不写入任一档案；本地同一身份证号重复时保持跳过并记录原因。
- 导入记录增加专项档案新增/更新数量，方便回溯本次导入影响。

## 验证

- 对截图所示党员表：从第 4 行识别表头，导入人员通用字段、入党日期和转正日期，并写入党员台账。
- 同一党员再次导入时更新同一人员和同一党员台账，不产生重复记录。
- 退役军人与低保表至少覆盖一组专属字段和一列“其他信息”。
- 测试标题、基础党支部信息、表尾合计/签字行均不进入人员或专项档案。
- 测试手动映射覆盖自动映射，未选择的列不写入任何档案。
