# 旧试用遮罩与登录入口修复实施计划

1. 在本地认证渲染层加入无条件的旧试用界面清理函数，覆盖弹窗、背景模糊和指针事件拦截。
2. 将启动、退出登录和进入工作台统一改为新版认证视图切换，不再调用旧版 `showPanel`。
3. 在进入工作台前后执行遮罩清理，并以短期观察器阻止旧版异步代码重新挂出试用弹窗。
4. 调整自动化测试，验证登录页为唯一启动入口、旧弹窗被隔离、工作台切换仍走兼容加载流程。
5. 将应用版本更新为 v0.2.4，运行完整测试并构建、挂载检查 arm64 拖拽安装 DMG。
6. 仅暂存本次修改的文件，提交并推送至当前 `origin` 分支；随后发布 v0.2.4 安装包。
