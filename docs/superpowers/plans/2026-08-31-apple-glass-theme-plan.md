# 苹果玻璃风主题实施计划

> 设计依据：[2026-08-31-apple-glass-theme-design.md](../specs/2026-08-31-apple-glass-theme-design.md)

## 1. 建立统一主题基础

- 在 `app/src/renderer/style.css` 顶部整理浅色与深色的颜色、玻璃面板、描边、阴影、文字和状态变量。
- 保留现有 `light-theme` / `dark-theme` 切换机制，使晨雾翡翠为默认浅色、夜航深海为深色模式。
- 为不支持背景模糊的环境提供更高不透明度回退样式。

**验证：** 检查主题变量在两种主题下都有完整定义，现有主题切换测试继续通过。

## 2. 改造应用骨架与登录页

- 调整应用背景、登录背景、侧栏、顶部栏、用户状态区和滚动条的玻璃层级。
- 统一圆角、细描边、投影、选中态和悬停态，确保较矮或较窄窗口不会产生截断。
- 保持登录控件、账号服务状态和错误提示的文字对比度。

**验证：** 运行登录布局测试，并在浅色、深色下检查登录页与工作台骨架。

## 3. 改造业务卡片、表格和表单

- 为统计卡片、筛选区、表格容器、输入控件、分页、状态标签和操作按钮应用统一玻璃规则。
- 对资金发放中心、财务、人员档案和长表格使用更高不透明度的阅读表面，保持金额、列标题与审核状态清晰。
- 不调整字段、数据、权限或业务操作。

**验证：** 在资金发放中心与典型业务表格中检查可读性、行悬停、滚动和危险操作提示。

## 4. 改造弹窗、提示与深色模式细节

- 更新弹窗、确认框、Toast、下拉菜单、文件选择与浮动 AI 入口的玻璃背景和焦点样式。
- 补齐深色主题下的正文、边界、输入框、表格斑马线与状态色，避免依赖颜色作为唯一提示。
- 降低不必要的过渡动画，支持系统减少动态效果偏好。

**验证：** 检查弹窗、通知和键盘焦点在浅色、深色下均清晰可辨。

## 5. 回归、打包与应用内发布

- 新增或调整样式结构测试，运行完整应用与后端测试。
- 进行 ARM64 打包验证，检查主题资源与签名。
- 按已授权的发布流程提升版本号、写入发行说明、创建并推送匹配的版本标签；确认 GitHub Release 同时包含 DMG、ZIP 与 `latest-mac.yml`，并由更新后端确认版本后再交付应用内更新。

**验证：** 已安装应用可通过“检查更新 → 立即更新 → 重启并安装”完成升级，升级后主题切换与资金发放中心正常工作。
