# 管理员后台与账号同步实施计划

1. 扩展后端账号服务与路由：增加用户筛选分页、账号详情、管理员重置密码和总览统计；对授权、模型配置进行严格校验，并为关键管理操作写入审计日志。
2. 增加内置静态管理网页：在 `/admin` 提供登录页与数据总览优先的单页后台，调用受保护 API 管理账号、在线 API 模型、用量、版本和日志。
3. 为桌面端增加远程认证服务：通过 `COMMUNITY_AI_BACKEND_URL` 配置后端地址，注册与登录使用后端 API；本地仅保留加密登录态、记住登录信息和展示所需的账号数据。
4. 在 Electron 主进程中切换到远程认证服务，保留 IPC 与渲染层接口名称，避免登录页和其他业务模块发生无关变动。
5. 添加后端与桌面端认证服务测试，运行两端测试、人工检查静态后台页面；只提交本次变更并推送当前分支。
