# 公文拟写 A4 预览与打印实施计划

## 任务 1：建立回归测试

- 扩展渲染层测试，覆盖 A4 预览容器、缩放控件、字体全文应用和“打印预览”入口。
- 扩展导出服务测试，覆盖 A4 PDF 生成、可见预览窗口和临时文件清理。

## 任务 2：固定工作区与 A4 缩放

- 修改 `app/src/renderer/js/document-drafting-ui.js`，增加预览视口、A4 画布舞台和缩放状态。
- 修改 `app/src/renderer/style.css`，让左栏与右栏在窗口内独立滚动，并让 A4 画布按真实毫米尺寸缩放。
- 监听窗口和正文尺寸变化，自动更新“适合页面”与“适合宽度”。

## 任务 3：修复字体应用

- 校准 macOS 中文字体回退顺序。
- 有有效选区时只调整选区；无选区时同时更新标题与正文的全文设置。
- 全文修改时清除冲突的旧局部覆盖，避免视觉上没有变化。
- 防止已失效的旧选区被再次使用。

## 任务 4：真实打印预览

- 复用现有打印 HTML 和 A4 参数生成 PDF 分页结果。
- 点击打印后打开可见 PDF 预览窗口，用户从预览进入 macOS 系统打印。
- 预览关闭后清理仅本次使用的临时 PDF。

## 任务 5：验证与交付

- 运行完整自动化测试。
- 启动应用检查缩放、独立滚动、字体与打印预览。
- 重新生成 Apple Silicon DMG 并计算校验值。
