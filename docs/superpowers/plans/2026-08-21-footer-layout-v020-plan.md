# v0.2.0 底部栏紧凑排版实施计划

1. 更新侧边栏底部操作行的结构标识，使四项操作可被统一样式约束，且不影响动态插入的“检查更新”按钮。
2. 为账号信息行和操作行增加紧凑 CSS：等宽单行网格、固定按钮高度、不换行、统一图标间距，以及窄窗口降级规则。
3. 将 `app/package.json` 与 `app/package-lock.json` 的版本更新为 `0.2.0`。
4. 运行 HTML 操作项定位检查、CSS/JavaScript 语法检查、更新界面测试和完整测试套件。
5. 构建 Apple 芯片 Mac 发布包，校验输出版本号后创建 GitHub `v0.2.0` 发布并上传安装文件。
