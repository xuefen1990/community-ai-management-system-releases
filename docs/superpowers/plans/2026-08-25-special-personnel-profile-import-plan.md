# 专项人员档案字段导入实施计划

> 设计依据：`docs/superpowers/specs/2026-08-25-special-personnel-profile-import-design.md`

## 1. 建立专项字段定义与记录构建器

- 在共享层定义通用人员字段、党员/退役军人/低保等专项字段及表头别名。
- 根据选定专项身份生成映射下拉框，构建专项档案记录并将未映射列保存为“其他信息”。
- 提供按身份证号查找、非空字段合并与党员台账记录构建函数，便于单元测试。

## 2. 扩展导入弹窗和写入流程

- 在专项标签确定后显示该专项的专属字段映射；保留通用人员字段映射和手动选择能力。
- 导入时更新统一人员档案与 `specialPersonnelProfiles` 专项档案。
- 对党员额外新增/更新 `partyMembers`，采用现有台账识别的姓名、身份证号、党支部、入党时间和阶段字段。
- 在导入摘要、完成提示和导入记录中显示专项档案新增/更新数量。

## 3. 回归测试

- 测试党员表映射：公民身份证号码、联系电话/手机号、家庭住址、加入党组织日期、转正日期可自动匹配。
- 测试党员导入同时创建人员档案、专项档案及党员台账，重复导入不生成重复记录。
- 测试退役军人和低保字段写入专项档案，并保留未映射列。
- 保留标题行与无效尾行过滤回归覆盖。

## 4. 验证与交付

- 运行专项档案、人员导入、党员统计和主进程预读相关测试；运行完整测试套件。
- 仅提交本次源代码、测试和计划文档。
- 如果完整测试套件通过，提交并推送到当前 `origin`；否则保留提交并说明阻碍发布的失败项。
