## 保留旧词的用途

| 保留位置 | 原因 |
| --- | --- |
| `社区AI管理系统` 数据目录、开发副本来源路径 | 沿用已有数据、账号配置、备份和共享资料，不迁移或重写正式数据 |
| 内部应用名和加密标识 | Mac safeStorage 用内部应用名定位钥匙串密钥，保留旧身份；显示名称通过独立品牌常量、窗口、菜单、托盘和关于面板提供 |
| `社区AI授权工具` 数据目录 | 授权工具读取已有设置，授权格式和应用标识不变 |
| 旧 Excel 表头、证明字段、识别正则、模板文件路径及内部键 | 保持旧输入、已保存模板及原模板文件可用；显示标签使用新称呼 |
| “村民委员会”等机构名称 | 机构名称按实际资料沿用，正文不对用户原资料做全局替换 |
| 已保存自定义模板、已开具证明、真实单位名称、地址、财务摘要 | 保留原文；旧模板及历史正文可能仍出现“社区／村民” |
| 原参考资源、项目目录、仓库及历史发布文档 | 保留来源和历史记录，仅更新当前生成结果与品牌文档 |

加密标识与显示名称在 `app/src/main/product-brand.js` 分开定义。依据项目固定 Electron 31.7.7 的[原生初始化实现](https://github.com/electron/electron/blob/v31.7.7/shell/browser/electron_browser_main_parts.cc)，不把运行时内部名称改成新的钥匙串命名空间；已有密文及账号服务隔离保存方式不变。
