# 人员 Excel 导入表头识别与无效行过滤实施计划

> 设计依据：`docs/superpowers/specs/2026-08-25-personnel-excel-header-and-invalid-row-filter-design.md`

## 1. 抽取可复用的表格解析模块

- 新增一个不依赖浏览器 DOM 的人员表解析模块。
- 内置现有人员字段别名、表头标准化、前 20 行扫描、重复/空列命名和有效身份证号行过滤。
- 返回列名、有效数据行、表头的 Excel 行号、忽略行数量，以及面向用户的错误信息。
- 身份证号校验复用与专项人员合并一致的 18 位身份证校验规则。

## 2. 接入两条读取路径

- 将主进程 `readExcelPreview` 改为调用新解析模块，而非默认移除第一行。
- 将页面端 `readSelectedFile` 改为调用同一模块；仅保留文件 ArrayBuffer 读取和弹窗渲染职责。
- 在导入状态中保存表头行号与忽略数，在映射弹窗中显示它们。

## 3. 加入回归测试

- 为解析模块测试顶部标题、标准首行表头、没有可识别表头、无有效人员行及表尾无效行。
- 扩展主进程 IPC 测试，验证带标题和表尾说明的工作簿只预览有效人员行。
- 扩展页面导入测试，验证页面读取仍使用共享解析规则且展示过滤信息。

## 4. 验证与交付

- 运行新增解析模块、主进程 IPC 与页面导入相关的自动测试。
- 检查完整测试套件，确认导入记录计数、预览和既有身份证号合并逻辑未受影响。
- 仅暂存本次新增或修改的源代码、测试与文档，提交并推送到当前 `origin` 分支。
