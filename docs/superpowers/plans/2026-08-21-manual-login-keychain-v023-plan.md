# 社区AI管理系统 v0.2.3 手动登录与钥匙串记住密码实施计划

> 当前工作区没有可调用的 `writing-plans` 技能，以下按同等粒度记录实施步骤。

1. 为本地认证增加 macOS 钥匙串凭据存取服务：使用 Electron `safeStorage` 加密密码，支持读取、保存、删除和降级处理。
2. 扩展受限 IPC 与预加载桥接：渲染进程仅能取得预填信息和请求清除已记住凭据。
3. 调整认证状态读取：保留已记住账号用于预填，但不再将其恢复为登录会话。
4. 调整登录界面启动与提交：启动固定显示登录页，预填用户名和隐藏密码；仅手动点击登录后进入工作台。
5. 新增“切换账号”操作，清空表单及钥匙串凭据；取消记住登录时删除已保存密码。
6. 将底部改为已选定的紧凑双按钮布局，更新相关样式和文案。
7. 添加服务与渲染测试，运行完整测试套件；更新版本、构建并验证 v0.2.3 DMG。
8. 仅提交本次文件并推送，创建 v0.2.3 GitHub Release，上传 DMG、ZIP 与更新信息。
