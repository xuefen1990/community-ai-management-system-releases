# 统一资金发放中心实施计划

> 本文只定义实施顺序；在用户明确要求开始开发前，不执行代码改动。

## 目标

把现有“承包费发放中心”扩展为不依赖合同的统一资金发放中心，同时完整保留现有承包费历史与按组发放能力。

## 实施步骤

### 1. 建立通用数据模型与兼容迁移

- 在本地和单位共享工作区的数据规范中新增：资金类别、发放批次、发放明细、临时收款人和批次附件。
- 将现有承包费台账映射为通用发放批次及明细，保留原始合同、组别、批次快照和状态字段。
- 合同关联改为仅“承包费”类别可选字段；不得阻止其他类别建批次。
- 增加数据归一化和迁移测试，确保旧数据读取后不丢失、不重复。

### 2. 实现类别管理与批次服务

- 提供预置类别：承包费、补贴、固定工资、杂工工资、公共服务运行人员工资。
- 支持管理员新增、改名、停用自定义类别；历史批次保存类别名称快照。
- 提供新建、编辑、审核、发放、查询和归档批次的服务接口。
- 直接标记为已发放时强制要求经办说明。

### 3. 统一收款人和附件能力

- 收款人优先从居民档案选择，并带出姓名、组别和默认银行卡。
- 增加临时收款人记录，支持非居民或外聘人员，但不要求创建居民档案。
- 复用安全文件存储方式，为批次增加可选附件；附件缺失不得阻断审核或发放。

### 4. 手工录入与 Excel 导入

- 新建批次时允许手工逐人添加发放明细。
- 将现有承包费 Excel 读取能力抽象为通用导入流程；类别可定义自己的列映射与校验。
- 导入后允许操作人员修改、增加、删除明细，并显示居民姓名匹配与未匹配结果。

### 5. 重构资金发放中心界面

- 首页改为年度/月度汇总看板：发放总额、待审核、已发放、类别汇总。
- 批次列表支持类别、期间、状态、组别筛选。
- 新建批次流程先选类别，再选手工录入或 Excel 导入；不先要求选择合同。
- 保留承包费专属的合同与按组规则，但只在选择承包费时显示。

### 6. 导出与历史查询

- 承包费与补贴支持按组拆分或汇总导出。
- 工资、杂工工资、公共服务运行人员工资及自定义类别默认整体导出。
- 历史批次可查看收款明细、状态流转、经办说明和可选附件。

### 7. 验证与发布

- 为数据模型、状态转换、类别快照、居民匹配、临时收款人、导入、导出和附件增加单元测试。
- 验证已有承包费台账和导出不回归。
- 完成后更新版本号、发行说明、Git 标签并发布应用内更新包；仅在 ZIP、DMG 和更新清单均验证发布成功后，通知用户在 App 内更新。

## 非目标

- 本次不接入银行自动打款。
- 不强制所有批次关联合同。
- 不强制上传银行回单或签字表。
