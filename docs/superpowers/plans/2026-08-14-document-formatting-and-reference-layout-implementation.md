修改公文拟写服务，增加版式默认值、白名单校验、草稿/版本快照和上一份版式继承。补充服务测试，覆盖首次默认值、跨请示报告继承、保存和版本恢复。

## 阶段 2：AI 公文结构与安全富文本

将 AI 纯文本结果转换为带有标题、抬头、正文、落款语义的安全 HTML。扩展 HTML 清理器，仅保留允许的字体、字号和对齐信息。补充兼容旧正文和异常 AI 输出的测试。

## 阶段 4：Word、PDF和打印

重写公文导出布局映射，使 OOXML 与打印 CSS 共用版式快照。解决标题重复，并验证参考样稿的 A4、字号、行距、缩进、对齐和页边距。
