# AI 助理模型分流与 Token 控制完成报告

**日期：** 2026-09-21  
**范围：** 阶段 6——基础 AI、深度 AI、预计用量、实际结算和额度不足恢复  
**状态：** 代码、桌面端与后端测试、开发模式检查完成，待开发版体验验收

## 已完成

1. 普通对话、意图理解、单表说明等任务标记为“基础 AI”；
2. 跨模块分析、多文件核对、证明起草和公文拟写标记为“深度 AI”；
3. 本机规则和数据库可以直接完成的查询仍然优先在本机完成，不无故消耗在线 Token；
4. DeepSeek 配置中存在 `reasoner`、`R1`、`pro` 等推理模型时，深度任务自动优先选择；没有推理模型时继续使用当前默认模型；
5. 深度 AI 执行前显示模型名称、预计最多使用的 Token 和当前剩余额度，并由工作人员确认；
6. 额度不足时不发送请求，保留对话框中的输入内容，并明确提示联系平台管理员购买额度；
7. 后端继续使用原有永久额度机制，先预留、成功后按实际用量结算、失败后退回预留额度；
8. 每次在线请求记录任务编号、任务类型、模型等级、模型名称、预估用量、实际用量和请求编号；
9. AI 任务可保存模型等级、模型名称、预计 Token、实际 Token、额度状态和剩余额度快照；
10. 任务执行中发现额度不足时停留在当前步骤，购买额度后可继续，不把任务误标成永久失败；
11. AI 助理任务卡片和顶部状态使用中文显示“基础 AI / 深度 AI”和实际 Token；
12. API 密钥仍只保存在后端，桌面端只接收可用模型、额度和结算结果。

## 使用效果

- 普通资料查询：系统优先使用本机规则或基础模型；
- 证明、公文或复杂分析：发送前先显示预计用量，确认后再执行；
- 请求完成：界面显示本次实际使用的 Token；
- 额度用完：输入和任务现场保留，购买额度后可继续；
- 平台管理员：继续通过现有后端管理单位永久额度和购买增加的额度。
