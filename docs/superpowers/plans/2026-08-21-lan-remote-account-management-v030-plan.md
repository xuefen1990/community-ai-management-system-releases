# v0.3.0 局域网账号与授权管理实施计划

1. 让后端明确监听局域网接口，并补充私有环境配置示例与启动说明，不写入真实管理员凭据。
2. 在桌面端认证状态中保存每台电脑的账号服务器地址；增加地址格式校验、健康检查与切换服务器时清除会话。
3. 通过既有 IPC 与预加载桥接暴露读取、保存和检测服务器地址的能力。
4. 在登录页加入紧凑的账号服务器入口和配置弹窗，注册与登录均使用已保存的服务器地址。
5. 补充远程认证、IPC、渲染层及后端联调测试：注册后后台可见、管理员修改限期或永久授权、客户端重新登录读取新状态。
6. 将版本更新到 0.3.0，运行两端完整测试，局域网启动验证，构建 Apple Silicon 可拖拽 DMG，提交、推送并发布。
