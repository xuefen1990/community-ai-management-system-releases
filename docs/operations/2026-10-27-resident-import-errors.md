# 居民导入按行处理及错误表格导出

用户确认的最终口径：正确行正常导入；错误行列出原因并跳过；导入完成后可以一键导出错误行，修正后重新导入。

- 普通居民导入的完成页沿用“导出异常清单 (.xlsx)”入口。导出内容升级为原表全部列，加原表行号、错误原因；导入前也可单独导出。
- AI 文件导入的预览和完成结果均提供“导出错误信息”；新增、补充行可独立成功，错误/冲突行保留在错误清单。
- 原始列、电话与户号前导零、18 位身份证按文本保留；类似公式的输入作为文本导出，不执行。
- 仅处理错误行；未更改正确资料的只补空白规则或居民人工合并规则。所有行都错误时不写居民资料，仍可导出修正。
- 导入历史保留错误行及原因。身份证只校验格式、出生日期和校验位，不代表联网核验真实身份。

验证：878 项应用测试通过；临时 Electron 副本实际导入正确行、跳过错误行、完成页导出 Excel，并重新读取核对姓名、原始电话/地址和错误原因。合成表格的错误行修正后重新导入测试通过。正式居民数据未用于测试。
