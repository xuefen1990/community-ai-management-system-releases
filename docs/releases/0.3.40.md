# 0.3.40

## AI 助理（第二阶段）

- 资金发放查询扩展为按居民、村民组、资金类别或合同的自然年度统计；例如可询问“2026 年哪个组发放最多”。
- 统计统一只计算状态为“已发放”的通用发放批次和合同发放批次，并说明统计范围、金额、笔数与涉及人数。
- 可查看各业务台账的实时记录数量，包括村民、党员、民情、值班、财务、土地、合同、工作、电子档案和证明。
- AI 助理可受控打开资金发放、村民档案、党员、民情、值班、财务、土地、工作管理、公文、证明、电子档案、统计和系统设置页面。
- 查询对象、年度、村民组或类别无法唯一确定时，AI 助理会继续询问，不会猜测、跳转到不确定对象或修改任何数据。
