# 社区AI管理系统 v0.3.43

## AI 助理升级

- 右下角“AI 助理”可直接回答年度发放、待发资金、值班、合同、土地、财务、公文和证明等系统问题；信息不明确时会先询问，不会猜测。
- 支持跳转到对应业务页面，并可在确认后办理居民资料、地块、民情、值班、工作、合同、财务和系统设置等常用事项。
- 所有实际修改均写入“AI 助理记录”，可按模块、类型、日期和状态查询，并只能在记录中心手动撤销。
- 删除、批量删除、清空财务台账、恢复系统备份和停用成员登录均采用两次确认；高风险操作保留快照或安全备份，冲突时自动拒绝执行。
- 成员账号不采用硬删除：AI 助理只能按既有单位权限停用和恢复成员，保留账号及历史记录。

## 稳定性与界面

- 修复备份恢复过程中的审计记录衔接，恢复前会自动保存当前状态。
- 统一 AI 助理记录中的高风险操作说明与筛选入口。
