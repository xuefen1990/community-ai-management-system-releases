# 社区AI管理系统 v0.3.64

## 资金发放中心整理

- 资金发放中心调整为“新建发放、未完成发放、历史发放、模板管理”的清晰流程。
- 新建发放支持从模板开始，或上传 Excel 识别后选择对应模板继续编辑和打印。
- 模板支持新增、修改、复制、删除和恢复；删除模板不会影响已保存或历史发放表。
- 已完成批次集中到历史发放，可按姓名、身份证号、银行卡、组别、日期或模板查询，并可重新打印、复用人员或删除到回收站。
- 测试批次不再计入正式统计，完成测试批次不会写入居民档案或个人操作记录。
- 保留原有地力补贴专项台账，以及已完成的可视化打印预览功能。
