# v0.3.55

## 资金发放中心可视化管理

- 全部发放批次增加按姓名、身份证号、银行卡号、村民组、日期和模板的统一查询；测试数据可整笔移入回收站、恢复或彻底清除。
- 发放批次可以复制为草稿，新批次会重新读取居民档案中的姓名、组别和默认银行卡，避免沿用过期卡号。
- 默认模板现可直接修改，也可恢复系统原始样式；打印预览支持拖动列顺序、设置列宽、显示或隐藏列，并可保存为模板版式或新模板。
- 发放前增加可视化核对提醒：重复人员、缺少银行卡、银行卡变化、重名待确认与手工调整金额均会明确显示。
- 工资、杂工、公共服务、承包费和自定义发放表统一提供“同步居民资料预览”：身份证优先匹配，资料冲突必须人工选择保留原档案或采用本次资料，确认后才写入居民档案。
- 居民档案新增“资金记录”标签页，可查看已同步的工资、承包费、杂工和其他资金发放来源。
