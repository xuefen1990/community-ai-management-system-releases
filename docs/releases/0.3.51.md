# v0.3.51

## 资金发放模板

- 新增发放模板管理：内置岗位工资、公共服务人员、杂工和承包费模板，也可新建自定义模板、字段、纸张和每页人数。
- 新建发放批次时，选择居民会自动带入姓名、组别和默认银行卡；同名居民会显示组别及身份证或银行卡尾号，必须人工确认。
- 支持自动金额计算与手工调整；调整金额必须填写原因，并随批次保存。
- 打印预览支持 A4、A5 和自动分页；已保存批次保留模板与居民资料快照，并可按“草稿 → 准备打印 → 已打印 → 已发放”管理。

## 同步包含

- 同步包含 v0.3.50 的 AI 助理发送修复，点击发送、按回车和快捷指令都会读取实际输入内容。
