# 村居AI管理系统 1.4.3

本版交付 Mac ARM64 与 Windows x64 完整安装包，并发布到现有 GitHub 仓库。

- 系统设置新增“地图与村界”：可配置自己的天地图服务密钥，定位村名、调整村委会标记和缩放，保存后同步到本机数据大屏。既有村界数据保留，服务密钥仅在本机保存，不进入业务备份或安装包。
- 数据统计更新为居民档案、党务、民情工单、村务值班、财务收支、土地承包六个分区，支持年度筛选、统计下钻与数据大屏。统计读取本机真实业务记录，保持财务分类及金额口径，区分无权限、加载失败与真实零值。
- 左下角工具栏调整为账号状态加四个快捷入口：数据大屏、手机互联、皮肤字号、更多。授权刷新、数据存储说明与退出操作收进“更多”，支持键盘操作并适配小窗口和深色主题。

保留原有本机账号、数据目录、历史资料与菜单个性设置。安装包不包含居民资料、密码或 API 密钥。

## 下载与更新

Mac 下载 ARM64 DMG，将应用拖入“应用程序”；Windows 下载 x64 EXE 安装。更新前备份资料并退出旧版，再覆盖安装。继续采用本机独立版的完整安装包更新，本次不登记旧云端应用内更新。

在线底图和地名搜索需要用户自行在设置中配置有效的天地图密钥；没有密钥时可查看本机配置，页面会提示服务尚未配置。

本次不包含自定义台账、Android 或微信小程序变更，不修改网站或部署 ECS。Mac 使用本机签名，未完成 Apple 公证；Windows 安装包未配置数字签名。

Windows 实机或虚拟机安装与启动验收仍待完成，不能以构建成功代替实际设备验收。完整验证结果随发布记录提供。
