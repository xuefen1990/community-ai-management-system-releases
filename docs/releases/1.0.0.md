# 社区AI管理系统 v1.0.0

首个 1.0 正式版，面向社区日常档案、证明办理、资金发放与 AI 辅助工作。

## 主要功能

- 居民一户一档支持居民资料、家庭成员、身份信息及关联记录的统一管理。
- 证明管理支持按模板填写、居民资料匹配、预览、打印与证明记录管理；AI 可协助拟写证明草稿。
- 电子档案柜支持文档和图片导入、识别、分类及归档核对。
- 资金发放支持按项目和组建立台账、导入表格、核对金额并导出明细。
- AI 助理支持连续对话、图片和文件分析，以及 AI 使用额度查看。
- 单位主账号可管理子账号、模块权限和 AI 使用权限。

## 平台

- Apple 芯片 Mac（ARM64）安装镜像。
- Windows x64 安装程序。

发行前运行项目自动测试，并分别核对平台安装包及应用内更新文件。
