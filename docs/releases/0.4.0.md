# 社区AI管理系统 v0.4.0

## 界面与基础

- 采用村务通 v2.6.4 的界面基础，统一侧栏、统计卡片、筛选栏、表格、弹窗和分页交互。
- 居民档案默认每页显示 15 人，复用筛选排序结果，合并初次加载请求，减少翻页和滚动时的重复计算。
- 保留资金发放中心、工作事项、公文拟写、AI 助理、操作记录和居民账户等定制功能，并接回现有社区账号、数据库和应用更新。

## 数据与业务

- 人员、户、组及业务页面适配原有数据，保留居民 ID、银行账户和其他已有字段。
- 跨页面表单保存合并实际修改，保留其他页面已保存的数据；同一字段冲突时提示重新载入。
- 人员、土地导入先生成快照再写入；完整备份包含可找到的附件及内容校验，恢复前保存当前状态。
- 电子档案接入文件归档和预览、手机上传；手机链接限时有效并绑定当前账号。
- 账号退出清理业务界面，页面刷新保持新版入口；授权状态的并发读取合并，手动刷新仍重新检查。

## 验证与回退

- 完整工程、原版 App 和应用数据已备份并逐文件校验，回退说明保存在“社区AI管理系统-改造前备份-20260907-150817”。
- 自动化回归 394 项通过，另以浏览器和临时 Electron 客户端验证表单保存、导入、页面切换、文件预览、手机收件及退出登录。
- 一万名合成居民测试中仅渲染当前页 15 行；性能结果来自隔离测试，实际使用速度取决于设备、数据和服务状态。
