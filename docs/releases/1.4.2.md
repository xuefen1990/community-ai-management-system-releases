# 村居AI管理系统 1.4.2 本机独立版

本版交付 Mac ARM64 与 Windows x64 完整安装包，并上传对应源码及 GitHub Release。

- 居民档案发现重复身份证或疑似同人时提示核对，提供“查看差异并合并”入口。由主电脑主账号选择主档、核实姓名与身份证后确认；主档非空内容保留，补齐空白，合并标签、账户及历史资料。合并前自动备份，原档归档；户号冲突须先核实。
- 普通居民导入和 AI 文件导入按行处理：正确行正常导入，身份证错误、缺失或其他异常行跳过并列出原因；不会因为一条错号阻止其他正确行。
- 导入完成后一键导出错误 Excel，保留原表全部列、原表行号和错误原因。身份证、手机号、户号按文本保存；修正错误后可直接重新导入。
- 保留既有只补空白、人工确认姓名冲突、预览后版本检查等保护。号码校验覆盖格式、出生日期及校验位，不代表联网核验真实身份。

## 下载与使用

Mac 下载 ARM64 DMG，将应用拖入“应用程序”；Windows 下载 x64 EXE 安装。安装前备份资料并退出旧版。安装包不包含居民资料、密码或 API 密钥。

继续采用本机独立版下载安装包更新。本次交付不登记旧云端应用内更新，不修改网站或部署 ECS，不包含 Android / 微信正式包。

Mac 使用本机临时签名，未完成 Apple 公证；Windows 安装包未配置数字签名，系统可能提示来源检查。
