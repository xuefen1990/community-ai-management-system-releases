# 社区AI管理系统 v0.3.58

## 居民个人档案入口整合

- 在居民列表点击“查看个人全套档案与详情”后，直接打开当前居民的统一档案资料，并以只读方式展示基础信息、收款账户与扩展资料、地力补贴记录、资金与工作记录、操作记录、来源与更正记录。
- 在居民列表点击“编辑信息”，或在家庭档案中点击“编辑当前人员”后，打开同一套统一档案资料，并允许维护银行卡、默认收款账户和自定义扩展字段。
- 统一档案关闭后仍可返回原有家庭详情或基础信息编辑流程，原有居民资料维护方式保持不变。
- 当前居民按系统唯一编号或身份证号定位，避免同名居民被错误关联。
- 保留“居民资料标签”独立查询入口，便于跨居民快速检索。

## 验证

- 居民档案入口与只读/编辑模式针对性测试通过。
- 应用全量自动化测试 325 项全部通过。
