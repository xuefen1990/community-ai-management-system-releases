# 村居AI管理系统 1.4.1 本机独立版

本版交付 Mac ARM64 与 Windows x64 完整安装包，同时上传对应桌面源码。以已交付的 1.4.0 独立版为基线，加入用户确认的客户端 AI 设置界面。

- 在“系统设置 → 智能助理”填写自己的服务地址、模型名称、API 密钥与图片识别能力，供 AI 助理、公文拟写和报告共用。
- 提供“自用在线服务 / 本机模型 / 优先本机模型”三种方式；本机模型的扫描、导入和启停收进折叠区，适配小窗口与缩放。
- 密钥默认遮挡，眼睛按钮仅显示本次输入；保存成功清空输入，留空保留旧密钥。修复安全存储恢复后旧会话密钥遮盖新密钥的问题。
- 保留 1.4.0 已交付的本机账号验证、原账号与工作区迁移、局域网共享及既有桌面功能。独立模式无需旧阿里云账号后台，不扣旧平台积分；在线 AI 由所配置的模型服务商计费。
- 旧云端更新工作流改为手动触发，版本标签不再自动向旧服务器发布更新。

## 安装与使用

安装前先在系统中备份资料并退出旧版。Mac 下载 ARM64 DMG，将应用拖入“应用程序”；Windows 下载 x64 EXE 安装。安装包不包含用户资料、账号密码或 API 密钥。

独立版采用下载安装包更新。本次仅 GitHub 交付，没有登记生产应用内更新、修改官网或部署 ECS，也不包含 Android / 微信正式包。不要将本版视为旧云端自动更新已经恢复。

Mac 使用本机临时签名并通过完整性检查，未完成 Apple 公证；Windows 安装包未配置数字签名。请从本仓库下载并核对 SHA-256，系统可能显示来源提示。
