# v0.3.49

## AI 助理改进

- 查询村民、资金发放、合同、土地、党员、工作、电子档案、证明和排班时，答案会附带统计口径、原始依据和可跳转的台账入口。
- 同户人员关系可结合完整对话和已核对的本机档案进行理解；资料不足、同名或关系无法确认时会追问，不会猜测。
- AI 助理的快捷操作、确认卡片、操作记录、来源跳转和等待状态统一为浅绿色背景与深灰文字，避免浅色主题下文字或按钮看不清。

## 安全与稳定性

- 本机台账、网络或在线模型暂时不可用时，助理会明确说明本次未查询、未修改，并停止后续操作。
- 在线 AI 仅用于理解和分析；本机系统仍是数据查询、页面跳转和全部修改操作的唯一执行方。
- 修改仍需确认；删除、清空和恢复等高风险操作仍需二次确认，并保留操作记录和手动撤销。
