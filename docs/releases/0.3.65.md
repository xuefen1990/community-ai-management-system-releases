# 社区AI管理系统 v0.3.65

## 资金发放与居民资料完善

- 资金发放中心继续整理为清晰的“新建发放、模板管理、未完成发放、历史发放”流程，支持 Excel 识别后选择模板继续编辑、预览和打印。
- 打印预览支持 A4/A5、横纵向、每页人数、分页、小计与末页合计，并可调整边距、字体、字号、眉头、行高和列宽。
- 发放明细中的姓名可关联居民档案：唯一匹配时自动带入默认银行卡；同名时显示组别及证件/卡号尾号，必须人工确认。
- 发放完成后，确认过的银行卡等资料可同步到居民档案；同时写入不可直接修改的个人资金与工作操作记录，便于后续查询。

## 承包费发放

- 新增“承包费发放”年度方案：一个地块可配置多个组，每组金额固定后可按人口、亩数或固定金额分配。
- 发放人员以承包费基础台账为准，不会自动把全组居民加入；收款人可不是户主，也可以随年度新增、移除或复用。
- 自动计算以分为单位处理；未除尽尾差必须在预览中手工调整到具体收款人，并填写调整原因后才能打印或完成发放。
- 同一地块、同一年度内跨组出现同一收款人会要求人工确认；不同地块之间不会误报重复。
- 支持导入单组承包费表及包含“组别”列的混合组表；可保留集体留存金额及原因，并可将本次名单回写为后续复用的基础台账。
- 承包费打印复用既有 A4 可视化打印预览，历史批次和当时版式保持不变。
