# v0.3.57

## 资金发放可视化工作台

- 新建和编辑发放批次采用一人一行的表格，可选择每页 10、20、50 人，避免一次创建大量居民下拉列表。
- 输入姓名查询居民候选，重名显示组别与身份证尾号并要求人工选择；带入默认银行卡和配置的居民字段。没有银行卡时保持空白，不阻止保存或打印。
- 支持复用同类历史人员与版式。工资重新确认月份，杂工清空旧的用工日期、事项、工日和金额，承包费重新确认单价；原批次不变。
- 自动计算金额，可手工调整并填写原因；支持撤销、草稿自动保存及失败重试。不完整草稿可以保留，但不得误打印、导出或完成发放。
- 打印预览支持 A4/A5、横纵方向、四边距、整表和单元格字体字号、对齐和换行、标题与眉头、行高和列宽。行列可拖动或输入数值调整。
- 按实际内容高度分页并重复表头，预览仅渲染当前页；打印使用同一版式生成器。打印后确认成功才登记打印状态。
- 版式默认仅保存到当前批次，也可明确保存到当前模板或另存新模板；历史批次保留自己的模板快照。
- 发放完成后仍通过原有居民资料核对流程正式写入银行卡、资金与工作记录，编辑草稿不会提前修改居民档案。

## 数据保护与验证

- 保存前读取最新数据库，检查当前批次是否已被其他操作修改；发现冲突时阻止覆盖。
- 修复复制批次可能沿用原草稿标识的问题，副本的行号和单元格格式关联独立。
- Excel 导出沿用工作台字段、修改后的列标题和行列尺寸，银行卡保持文本格式。
- 通过全量自动测试、隔离浏览器交互测试、618 人长文本分页测试和正式菜单接入测试。测试使用虚构人员，不改动实际发放数据。
