# 社区AI管理系统 v1.2.0

## 主账号在多台电脑使用

- 主账号可在其他电脑登录并打开该电脑独立的本地工作区。首次使用时显示空数据，不会误读或覆盖本机其他主账号的数据。
- 同一电脑切换主账号后，各自的业务数据、附件、备份和 AI 历史保持隔离；切回原账号仍保留原数据。
- 本地数据不会随登录自动复制到其他电脑。子账号仍按原有方式连接所属主账号指定的局域网共享电脑。

## 安装与应用内更新

- 汇总 1.1.3 至 1.1.7 的更新修复：Windows 与 Mac 均从生产服务器检查和下载更新，Windows 安装包包含更新源配置。
- Windows 在具备旧包缓存时使用块索引和分段请求减少下载量；缺少缓存时可回退到完整包。
- 从 1.1.6 升级时，点击一次“立即更新”后自动下载、静默安装并重新打开新版。
