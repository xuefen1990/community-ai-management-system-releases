# v0.3.56

## 居民账户与个人资金记录

- 居民资料新增“收款账户与扩展资料”标签页：支持保存多张银行卡、设置默认收款卡，并在新建发放时自动带入默认卡。
- 支持管理员创建文字、数字、日期、单选、多选、是/否等扩展字段；字段默认对全体居民可见，不适用时可留空。
- 工资、杂工、承包费、补贴和自定义发放批次在“发放完成”后，才会正式把已确认的账户资料、资金来源和工作事项写入居民档案。
- 当发放表银行卡与默认卡不同，操作员可选择仅本次使用、登记为备用卡或设为默认收款卡；不会静默覆盖已有资料。
- 居民档案新增“资金与工作记录”和“操作记录”标签页，可分页查看发放金额、工作事项、账户来源和资料变更历史。
