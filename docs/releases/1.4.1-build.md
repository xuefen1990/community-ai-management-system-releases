本次 Git 提交以既有分支为基础，只加入已交付 1.4.0 桌面运行基线、本次确认的 AI 设置修改、对应测试与构建文档。未把桌面工作区的其他未确认开发内容、用户数据或凭据一并提交。

## 构建

使用 Node.js 20 与各项目锁定依赖。Windows：

```sh
npm ci --prefix app
npm ci --prefix backend
node scripts/build-win-x64.mjs
```

Mac 完整 DMG 使用已核验的 1.4.0 独立版 `.app` 提供 Electron、原生依赖及完整后端生产依赖：

```sh
node scripts/build-standalone-mac.mjs "/path/to/verified-1.4.0/村居AI管理系统.app"
```

该脚本校验应用依赖没有变化，复制独立运行时，覆盖当前 `app/src`、`backend/src` 与包清单，更新应用版本并重新本机签名，最后生成带“应用程序”链接的 DMG。依赖发生变化时必须重新准备完整运行时，不可沿用该覆盖流程。

本版原始 Mac 基线 DMG 的 SHA-256：`0200ddd765f773cc861492513d92b4eb1771f3d9c516f7ff5aab5ee25d3f82a4`。

## 测试

```sh
npm test --prefix app
```

配套后端运行 `backend/tests/` 中现有桌面相关测试，共 34 项。较新 Android 更新接口的 `android-update.test.js` 未纳入该桌面基线；本次不交付移动端更新服务。

Electron 交互测试必须使用合成资料与独立目录。`app/tests/renderer/standalone-ai-settings-electron-check.cjs` 使用模拟服务，不能当作真实模型连接凭证。打包副本启动测试也隔离应用数据目录，并屏蔽开机登录项设置；正式已安装应用不被覆盖。

本次只发布 GitHub 完整安装包。`.github/workflows/publish-desktop-update.yml` 已取消标签推送触发；旧云端发布仅能手动触发并明确勾选，不能随本次标签运行。
