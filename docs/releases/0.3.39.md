# 0.3.39

## AI 助理（第一阶段）

- 右下角入口更名为“AI 助理”，支持本次使用期间拖拽；关闭后自动恢复右下角默认位置。
- 可直接回答“某居民本年度共计发了多少钱”：只汇总已登记发放的通用批次和合同批次，并明确说明统计范围；未登记发放的地力补贴台账不会被误计入。
- 同名、年度或查询对象不明确时，AI 助理会要求确认，不会自行猜测；可受控打开资金发放中心。
- 首个对话式修改闭环上线：修改居民手机号时先展示修改前后内容，必须回复“确认”才会写入。
- 新增左侧“AI 助理记录”中心和窗口内快捷入口。已完成的 AI 修改可在记录中心手动确认撤销；查询和页面跳转不记录为数据操作。
