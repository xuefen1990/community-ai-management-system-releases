# 社区AI管理系统 v1.2.1

## 局域网主机与登录

- 系统设置直接显示当前电脑的局域网 IP，精简共享设置入口，方便其他成员输入主机地址。
- 子账号在本机首次使用时进入独立的主机连接页，可扫描或手动输入 IP，确认所属主机后进入工作台；后续优先自动重连，主机地址变化时可重新发现。
- 主机应用保持运行时，主账号退出应用登录也不影响已授权子账号连接。
- 已登录的本机业务在账号服务器临时断连时继续使用本地数据；需要在线 AI 的功能仍需连接服务。

## 数据与成员管理

- 数据与备份设置支持更改当前主账号工作区的存储位置，并保留原位置的数据副本。
- 新增和编辑成员改为独立的宽屏表单；权限按两列展示，支持全部及单个模块的全选、清空。
- 取消未保存的修改前会提示；保存失败保留表单内容，新成员的初始密码仍只展示一次。
