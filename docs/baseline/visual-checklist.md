- 窗口为近全屏宽屏比例，左上保留 macOS 红黄绿窗口按钮。
- 背景为浅绿色水墨乡村画面，带半透明重复水印。
- 中央卡片左右分栏，左侧为产品介绍，右侧为登录表单。
- 卡片使用白色与浅绿色面板、圆角和柔和阴影。
- 主色为绿色，正文为深灰，辅助文字为灰绿色。

## 暂不直接保存的原版页面

原应用在检查过程中自动进入已登录工作台，并显示真实村名、手机号、干部通讯录、人口统计和业务数据。为避免把真实村务数据固化到项目或提交记录，以下页面不从真实运行状态截图：

- 工作台
- 数据统计
- 村民一户一档
- 党员管理
- 民情记录
- 村里值班
- 财务收支
- 土地承包确权
- 证明开具
- 电子档案柜
- 系统设置

这些页面将在可开发副本接入全新空数据库后，以固定窗口尺寸采集默认、空数据、加载中和弹窗状态。界面 HTML、CSS、文字和 SVG 已在原始解包基线中完整保留，可作为视觉实现依据。

## 开发副本后续采集规范

- 固定窗口尺寸：1292 × 768 CSS 像素。
- 同时采集亮色与深色主题。
- 每个主要页面至少采集默认状态和空数据状态。
- 关键弹窗按 `page-inventory.md` 的 25 个弹窗逐项采集。
- 截图中只允许使用合成测试数据，不使用原版真实数据。
- 允许差异仅限名称、Logo、应用图标、本地授权和双 AI 设置。
