# 保存密码修复与下一次交付清单

根因：本地 account-gate 将 remember 交给锁定 foundation auth.login；该封装只接受 rememberPhone 并仅向登录 IPC 转发手机号和密码，因此主进程收到的保存开关始终为默认 false。

修复：展示扩展直接调用既有 loginProductAuth IPC，保留账号工作区切换、登录项设置、认证状态刷新、首次修改密码及原有登录后路由。传递用户勾选的 remember，并处理原有 ok/error 返回；沿用 RememberedLoginStore 与 Electron safeStorage 加密存储。不改 vendor、后端 API 或业务数据。

验证：
- 原生隔离界面通过实际登录表单、IPC、系统加密保存，以及退出后的自动回填；取消勾选后密码清空。
- 两个独立 Mac 进程验证保存后重启可解密，文件不含明文合成密码；不读取用户真实密码。
- 15 页往返切换、四组尺寸/缩放、表单弹窗、AI 助理、公文编辑器与深色主题通过。
- 应用现有及新增测试 799/799；启动更新检查新增检查时序、同次启动不重复、离线失败及不自动安装验证。

新版会在窗口启动时订阅更新状态后自动检查；同次窗口会话的刷新/退出登录不重复自动检查，新启动会再检查。发现更新沿用现有弹窗，需点击“立即更新”才下载，完成后自动安装并打开。

待确认版本建议：1.3.1（当前正式 1.3.0）。正式交付范围：保存密码修复、去掉顶部独立栏及底部按钮避让、启动更新提示；Mac ARM64 ZIP/DMG 与 Windows x64 EXE/块索引，生产应用内更新登记；官网 Mac/Windows 下载按钮显示新版本并指向同版本完整安装包。

官网当前按钮仍指向 1.2.0；已只读核对部署连接，安装包目录为 C:/community-ai/downloads，按钮配置为 C:/community-ai/website/dist/downloads.js。正式部署只替换对应下载文件与按钮配置，保留已有网站内容。

此时版本尚未确认，未升版本、正式打包、生产登记、官网部署或 GitHub 提交。Windows 实机自动安装重启验收仍需可用 Windows 环境。
