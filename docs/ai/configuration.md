# 双 AI 配置说明

社区AI管理系统支持三种运行方式：

- **仅本地 AI**：使用用户导入的 GGUF 模型，业务文本不离开本机。
- **仅在线 AI**：调用 OpenAI 兼容的 `/chat/completions` 接口。
- **自动模式**：本地模型已启动时优先使用本地；本地未启动或不可用时转到已配置的在线接口。

## 本地模型

模型目录位于应用独立用户数据目录下的 `models` 文件夹。设置页支持直接选择并复制 `.gguf` 文件，也保留“一键打开模型目录”的使用方式。

本地推理由 `node-llama-cpp` 按需加载，最终安装包仅面向 Apple Silicon（ARM64）。模型文件不随安装包附带。

## 在线接口

需要填写：

- 接口根地址，例如 `https://api.example.com/v1`
- 模型名称
- API 密钥

远程接口必须使用 HTTPS；HTTP 只允许 `localhost`、`127.0.0.1` 或 `::1`。API 密钥由 Electron 的 macOS 安全存储加密后落盘，不通过预加载桥返回给网页界面。

只有用户主动提交给在线 AI 的文本会发送到所配置的接口。村民档案数据库不会自动同步或上传。
