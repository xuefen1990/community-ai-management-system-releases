# 村居 AI 管理系统后端

该服务负责统一保存桌面端注册账号，并在网页后台管理主账号、子账号、在线大模型 API、调用用量、软件版本与审计日志。

## 启动

```bash
cp .env.example .env
npm ci
npm start
```

局域网测试时，先复制 `.env.example` 为私有 `.env`，并设置随机的 `JWT_SECRET`、管理员手机号和非默认的管理员密码。服务默认只监听 `127.0.0.1`；需要局域网访问时显式设置 `HOST=0.0.0.0`，然后在浏览器打开 `http://服务器局域网地址:3000/admin/`。`.env` 不应提交到仓库。

生产环境必须配置 `JWT_SECRET`、`ADMIN_PASSWORD` 与明确的 `CORS_ORIGINS`（例如正式网页后台所在的 HTTPS 来源），不可使用通配符。初次创建的平台管理员首次登录后必须修改初始密码。已有数据中模型 API 密钥目前也以 `JWT_SECRET` 派生密钥加密：轮换 JWT 密钥会使旧令牌失效，并使已保存的模型密钥无法解密；轮换前需安排密钥迁移或重新录入。后端应由 systemd 或其他进程管理器托管，未捕获异常退出后自动重启。

桌面端需通过环境变量 `COMMUNITY_AI_BACKEND_URL` 指向该服务，例如：

```bash
COMMUNITY_AI_BACKEND_URL=https://api.example.com npm start
```

v0.3.0 起，桌面端登录页可直接设置和测试账号服务器地址。正式安装版未设置时默认连接 `https://xuefeng0901.cn`；开发版继续使用本机独立后端。注册或登录无法连接该地址时会失败，以保证每个新账号都可在后端后台查看。切换地址会清除当前登录会话，需在新服务器上手动登录。

## 局域网测试流程

1. 在作为服务器的电脑中启动后端，并确认防火墙允许 TCP 3000 端口的局域网访问。
2. 在浏览器访问 `http://服务器局域网地址:3000/api/health`，返回 `status: ok` 即表示服务可用。
3. 在桌面端登录页点击“设置”，填写同一地址并执行“测试连接”。
4. 使用“注册新账号”填写手机号、密码和确认密码；注册后立即进入试用。随后访问 `/admin/`，平台管理员即可在“账号管理”中查看主账号并修改授权日期。

主账号可以直接用姓名和手机号开通子账号，并分配模块权限和 AI 使用权限。主账号与全部子账号共用同一份工作区、授权期限和永久 Token 额度；子账号不单独设置额度或有效期。

## 首版边界

- 仅一个超级管理员，由 `ADMIN_PHONE` 和 `ADMIN_PASSWORD` 初始化。
- 仅支持 OpenAI 兼容的在线模型 API；密钥加密保存且不会通过管理接口返回。
- 当前 JSON 数据文件适用于单个服务实例。部署到生产前请备份 `DB_PATH` 指向的数据文件。
