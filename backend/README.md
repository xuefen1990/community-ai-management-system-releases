# 社区 AI 管理系统后端

该服务负责统一保存桌面端注册账号，并在网页后台管理账号、在线大模型 API、调用用量、软件版本与审计日志。

## 启动

```bash
cp .env.example .env
npm ci
npm start
```

局域网测试时，先复制 `.env.example` 为私有 `.env`，并设置随机的 `JWT_SECRET`、管理员手机号和管理员密码。`HOST=0.0.0.0` 会让同一局域网内的电脑可以访问服务；服务启动后，在浏览器打开 `http://服务器局域网地址:3000/admin/` 登录管理后台。`.env` 不应提交到仓库。

桌面端需通过环境变量 `COMMUNITY_AI_BACKEND_URL` 指向该服务，例如：

```bash
COMMUNITY_AI_BACKEND_URL=https://api.example.com npm start
```

v0.3.0 起，桌面端登录页可直接设置和测试账号服务器地址。未设置时默认连接 `http://127.0.0.1:3000`；注册或登录无法连接该地址时会失败，以保证每个新账号都可在后端后台查看。切换地址会清除当前登录会话，需在新服务器上手动登录。

## 局域网测试流程

1. 在作为服务器的电脑中启动后端，并确认防火墙允许 TCP 3000 端口的局域网访问。
2. 在浏览器访问 `http://服务器局域网地址:3000/api/health`，返回 `status: ok` 即表示服务可用。
3. 在桌面端登录页点击“设置”，填写同一地址并执行“测试连接”。
4. 使用“注册新账号”创建账号；随后访问 `/admin/`，管理员即可在“账号管理”中查看该账号并修改授权日期。

## 首版边界

- 仅一个超级管理员，由 `ADMIN_PHONE` 和 `ADMIN_PASSWORD` 初始化。
- 仅支持 OpenAI 兼容的在线模型 API；密钥加密保存且不会通过管理接口返回。
- 当前 JSON 数据文件适用于单个服务实例。部署到生产前请备份 `DB_PATH` 指向的数据文件。
